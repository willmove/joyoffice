# Third party sources

JoyDeck uses the JoyOffice MIT-licensed public UI, workspace layout, engineering launchers and packaging/provenance foundations from commit `a973f75d7d58ab8dd5f05b0e3db5f0c53137d57d`. Copyright (c) 2026 willmove. The original license is retained in `licenses/joyoffice/LICENSE-MIT`; file paths, original hashes and adaptations are recorded in `licenses/joyoffice/source-map.json`.

GPUI Kit 0.8.1, its component/assets layers and the GPUI pre 0.3.10 snapshot are Cargo dependencies. Their actual selected packages and licenses are recorded in the development package SBOM. Imported sources are not represented as independently authored clean-room implementations.

The welcome preview in `tests/fixtures/joydeck/welcome.json` is original content licensed under the repository MIT license. Runtime system fonts are not bundled. No ArtCraft/DeckCraft trademarks or product artwork are imported.

The color, geometry, presentation-model, metafile, font, text, animation, CPU-render, native-format and PPTX libraries are adapted from the supplied DeckCraft 0.14.1 snapshot, Copyright (c) 2026 ArtCraft Team and the DeckCraft contributors, under the MIT option of its MIT OR Apache-2.0 license. Original notices and both license texts are retained in `licenses/deckcraft`. `licenses/deckcraft/file-map.json` records the actual imported files, original snapshot hashes and local namespace/formatting adaptations. The broader snapshot inventory does not imply that all upstream files are imported.

R1 also adapts the JoyOffice `joyoffice-opc` crate and the existing JoyDeck asynchronous viewer (virtualized thumbnails, cancellation and generation guards). Adaptations are recorded in the same source map.

The renderer embeds the unmodified Ubuntu Light font (Dalton Maag Ltd/Canonical, Ubuntu Font Licence 1.0); tests use Hack Regular (Source Foundry, MIT/Bitstream Vera). Exact source archive and asset hashes plus full licenses are in `licenses/fonts`. Only the independent font assets were selected; epaint/egui code and icon fonts are absent. Runtime system fonts are discovered locally and never redistributed. Optional external craft-fonts input is disabled for R1 until its sources and licenses are registered.

The `r1-preview` fixtures are original MIT content generated by `r1_corpus.rs`. `independent.pptx` is original content produced independently with python-pptx 1.0.2 (MIT; template license retained in `licenses/python-pptx-MIT.txt`) and Pillow; the generation script records the recipe. Upstream generated font fixtures are CC0-1.0, detailed in the retained `licenses/deckcraft/ATTRIBUTION-upstream.md`. Upstream engine-dependent format integration tests are retained under `tests-upstream` until the engine migration; they are not counted as passing R1 tests.

R2 extracts the pure copy-on-write history memory estimate from DeckCraft engine (mapped in the source ledger) and adapts JoyOffice platform file publication and shell leased recovery/fingerprint code to the new model and JoyDeck v2 packages. The R2 transaction subset and format-preserving integration are separately implemented adapters, not a claim that all upstream engine commands were migrated. Source checkouts remain read-only.

R3 adapts JoyOffice joydeck-model text range/grapheme helpers and composition-draft behavior, plus the existing JoyDeck canvas EntityInputHandler/clipboard routing and notes Textarea flow. The new presentation model still uses the retained DeckCraft rich-text editing and CPU text/table layout libraries; GPUI caret/hit/candidate geometry consumes that same layout. New adaptations and changed source hashes are recorded in the source ledgers. No upstream checkout is modified.
