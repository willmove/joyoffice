# JoyOffice 多语言与界面本地化

2026-11-26。JoyWord、JoyDeck 和 JoySheet 共用统一的多语言内核（`joyoffice-l10n`）与界面语言切换组件（`joyoffice-ui`）。界面语言只影响应用界面、菜单、提示和默认新建模板内容，不改写已有文档内容、公式、样式或保存／导出格式。

## 架构与分层

- `crates/joyoffice-l10n`：无 GUI、无文件访问、无外部依赖的公共本地化基础库（`unsafe_code = forbid`）。
  - `UiLocale`：工作区唯一受支持界面语言枚举（当前内置 `zh-CN` 简体中文与 `en` English），携带 BCP-47 标签、缩写标签、母语自称（Autonym）、英文名、书写方向（`is_rtl()`）、回退链（`fallback()`）、CLDR 基数复数分类（`Zero`/`One`/`Two`/`Few`/`Many`/`Other`）及旧配置标签兼容解析（如 `zh`、`zh_CN`、`en_US`）。
  - `Catalog` / `CatalogSet`：解析 `.lang` 词表（支持 `\n`/`\t`/`\\` 转义与 `{name}` 占位符插值、复数后缀 `key[one]` 等），按 `locale -> fallback -> en -> zh-CN -> key` 回退，并提供 `CatalogSet::parse_strict` / `validate_catalogs` 严格校验词表键集合、占位符和复数形式一致性。
  - `shared()`：提供跨产品公共词条（语言选择器文案与 8 套共享界面主题名称）。
- `crates/joyoffice-ui`：再导出 `joyoffice-l10n` 公共类型，并维护全局运行期语言状态（`AppliedLocale` / `apply_locale` / `current_locale`）及可扩展语言切换控件：
  - `language_menu` + `language_header_trigger` / `language_status_trigger`：标题栏／状态栏紧凑弹出菜单，纵向可滚动，按母语自称 + BCP-47 标签列出 `UiLocale::ALL` 全部语言并标记当前选中项。
  - `language_options_section`：选项／设置页可滚动卡片网格，支持未来扩展至数十种主流语言而无需重构界面布局。

## 各产品入口与偏好持久化

- **JoyWord**：
  - 入口：顶部标题栏语言下拉菜单、文件 → 选项 → 界面语言。
  - 持久化：`migration-preview/preferences.conf` 的 `ui.locale` 键（保持旧配置与 `view.language` 命令兼容；保存失败自动回滚）。
- **JoyDeck**：
  - 入口：顶部标题栏语言下拉菜单、底部状态栏语言按钮、文件 → 选项 → 界面语言。
  - 持久化：`recovery_root()` 下的 `language.v1`（与 `appearance.v1` 相邻，64 字节读取上限、原子保存与冲突检测；首次默认 `zh-CN`，忽略无效或超长文件）。
  - 命令行覆盖：`--lang=<tag>`（如 `--lang=en` / `--lang=zh-CN`）覆盖本次会话语言；仅在界面手动切换时写入持久化存储。
  - 词表位置：`crates/joydeck-ui-gpui/locales/{zh-CN,en}.lang`，通过单元测试强制键集合与占位符完全一致；同一进程内多个 JoyDeck 窗口实时同步语言切换。
- **JoySheet**：
  - 入口：功能区右上角语言下拉菜单、设置 → 界面语言。
  - 持久化：`preferences.json` 的 `language` 字段（兼容旧值 `"zh"`，写入规范 BCP-47 标签如 `"zh-CN"` / `"en"`）；原生控制接口 `ui.set` 接受任意 `UiLocale::from_tag` 支持的标签，`ui.inspect` 返回当前 `language` 与可用 `languages` 列表。

## 扩展新主流语言的步骤

为全部三个桌面应用新增一种主流语言（例如日语 `ja`、韩语 `ko`、法语 `fr`、德语 `de`、西班牙语 `es`、阿拉伯语 `ar` 等）仅需：

1. 在 `crates/joyoffice-l10n/src/lib.rs` 的 `UiLocale` 枚举与 `UiLocale::ALL` 中注册新变体，补充 `tag()`、`short_label()`、`native_name()`、`english_name()`、`is_rtl()`、`fallback()`、`from_tag()` 及对应 CLDR 复数规则，并添加 `crates/joyoffice-l10n/locales/<tag>.lang`。
2. 在各产品词表目录新增对应 `<tag>.lang` 并加入各自的 `SOURCES` 表：
   - `crates/joydeck-ui-gpui/locales/<tag>.lang`
   - `crates/joyword-shell/locales/<tag>.lang`
   - `crates/joysheet-ui-gpui`（后续可随词表化按相同模式接入 `CatalogSet`）
3. 运行单元测试（`cargo test -p joyoffice-l10n -p joydeck-ui-gpui -p joyword-shell`），`CatalogSet::parse_strict` 将自动验证所有键、占位符和复数变体完整一致。
4. 三个产品的标题栏下拉菜单、选项／设置页语言列表与 JoyDeck 状态栏语言按钮会自动呈现新语言，无需修改 UI 布局代码。

## 验证边界

- 自动化验证覆盖：`joyoffice-l10n` 解析／占位符／复数／回退与严格一致性测试；`joyoffice-ui` 主题名称与语言状态测试；`joydeck-shell` `language.v1` 持久化、冲突与非法输入拒绝测试；`joydeck-ui-gpui` 双语词表严格一致性与中英文启动模板测试；`joyword-shell` 词表与配置持久化回归；`joysheet-platform` 旧标签兼容与偏好往返测试；以及三产品编译、clippy 与仓库质量门禁。
- 人工真机／桌面实窗验收（含 Windows / macOS / Linux 各 DPI、输入法、读屏与 RTL 排版）需在对应图形桌面环境中补验。
