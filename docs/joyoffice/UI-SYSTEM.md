# JoyOffice 桌面 UI 规范

2026-11-01。首批消费者为 JoyWord 和 JoySheet。公共实现位于 `crates/joyoffice-ui`，通过现有精确固定的 GPUI Kit 0.8.1 提供视觉原语，不另引入 UI 框架。

## 职责与依赖

`joyword` 与 `joysheet-ui-gpui` 依赖 `joyoffice-ui`；公共 UI 仅依赖 GPUI Kit，不依赖任何产品模型、编辑引擎、文件服务、命令注册表或用户配置。产品之间没有新增依赖。

- 公共层拥有具名配色、逻辑尺寸、控件表面、卡片表面和图标呈现。
- 产品层拥有命令 ID、本地化标签、可用状态、选中状态、焦点上下文、辅助功能身份和事件处理。
- 文档字体、样式、页面场景和缩放属于产品内容；UI 字号、间距和图标不随文档缩放改变。
- 界面按钮继续调用既有命令／事务链路；共享控件不解析文件，不修改模型，不改变保存、只读或拒绝契约。

`scripts/check_gates.py` 明确登记公共 UI 和两个消费者的依赖边。只有具名呈现层可直接使用 GPUI，核心和 CLI 的无界面约束继续保留。新测试覆盖公共 UI 反向依赖产品、模型依赖公共 UI 的拒绝路径。

## 视觉规则

公共 `Palette` 使用 canvas、surface、chrome、header、text、muted、border、hover、pressed、selected 等语义名称。Word／Sheet 共用中性颜色，以蓝／绿强调色区分产品。浅色和深色均定义完整配色；首批 Word 使用浅色，Sheet 继续跟随原有浅深色偏好。定义深色配色不代表 Word 已有完整深色模式。

| 项目 | 逻辑像素 | 约定 |
| --- | --- | --- |
| 普通控件 | 30 | 图标和文字垂直居中；保留可见键盘焦点 |
| 标题栏 | 48 | 产品、文件操作、标题、保存状态 |
| 功能区标签 | 36 | 选中项使用强调色和下划线 |
| 状态栏 | 32 | 文档状态、页码／字数和缩放 |
| 普通图标 | 18 | 使用固定依赖中提供的 Lucide SVG |
| 控件圆角 | 6 | 输入、按钮与下拉统一 |
| 卡片圆角 | 10 | 功能区与格式弹窗 |

Word 功能区保留全量、紧凑和溢出三档；宽度小于 760 时工具区降为 54 像素，其他档为 106 像素。常用格式保留直达入口，其他操作通过现有“更多”菜单访问。样式卡片只来自实际文档样式，超过首批展示范围仍可通过样式侧栏访问；`Aa` 为通用识别符，不作为真实排版预览。

## 交互规则

- 悬停、按下、选中、焦点和禁用是独立状态；禁用命令继续拒绝执行，并发布辅助功能禁用状态。
- 图标按钮暴露本地化名称和稳定身份；格式开关发布当前选中值。
- 保留 Word 的独立工具栏／字段按键上下文，避免空格和 Enter 穿透正文编辑。
- 字体／段落／表格弹窗保持既有预填、输入、取消和单次撤销事务。预设项放在对应字段下方，提交与取消放在统一页脚。
- 一般技术预览横幅默认收起；打开、恢复、只读、元数据风险和保存错误的实际提示继续保留。
- 弹窗尺寸受窗口视口限制，内容可滚动；窄窗口不依赖把文本缩小来容纳操作。

## 本轮接入范围

JoyWord：主标题栏、功能区和图标、工具按钮、下拉菜单、样式卡片、查找／样式侧栏、状态栏，以及字体／段落／表格格式弹窗。原生平台提示继续使用系统行为，Linux 内部提示复用本轮配色。

JoySheet：主窗口背景、主要文字和边框、标题栏／标签／功能区配色，以及工具按钮的公共表面与尺寸。工作簿网格、计算、公式输入和业务面板的迁移状态不因本轮改变；其他面板中的历史样式仍可后续逐步归并。

## 验证

公共配色测试要求主要文字与次要文字对背景达到 4.5:1，对焦点／强调色要求至少 3:1，主要操作的前景／背景达到 4.5:1。该测试只覆盖定义的颜色组合，不宣称整款应用符合 WCAG。

实际构建、工程检查、原生操作与截图单列于[本轮验证](validation/20261101-ui/README.md)。Windows、Linux、真实读屏和信创设备需要各自记录，macOS 截图不能替代这些验收。
