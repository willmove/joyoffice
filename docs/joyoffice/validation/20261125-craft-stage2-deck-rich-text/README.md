# 阶段 2 · JoyDeck 富文本模型和编辑

形状坐标和变换先提交为 `ff53276a`。富文本回归沿用 `14cbb296` 的冻结 CLI，并用独立构造的 DrawingML 文稿核对保存和呈现结果。

## 实现

- 保留既有文稿模型的序列化字段。输入、替换、富文本粘贴和范围格式通过同一套段落和文字片段操作。多目标文字编辑统一发布，后续目标校验失败时保留原文稿。富文本粘贴保留后续段落的默认字符格式、列表级别及原有目标尾部的格式。
- 在模型解析直接字符格式、段落默认、文本框列表级别、版式和母版占位符、母版文本样式与文稿默认。编号状态按段落级别跟踪，保留起始值、连续编号、重启与空段落预览。[ECMA-376 Part 1](https://ecma-international.org/publications-and-standards/standards/ecma-376/) · [DrawingML 文本列表样式](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/438b915f-007e-4b90-839d-d80034a94f66) · [PresentationML 母版](https://learn.microsoft.com/en-us/office/open-xml/presentation/working-with-slide-masters)
- PPTX 保留保存支持在同一文本框的既有段落中组合编辑普通超链接、字符和段落格式、普通项目符号与编号。扩展或图片项目符号需保留原 XML 时维持另存提示。新链接关系随源关系部件使用正确的 OPC 命名空间。[ECMA-376 Part 2](https://ecma-international.org/publications-and-standards/standards/ecma-376/)
