- 用冻结版 `14cbb296`、上轮 `4b7d3711` 和候选版各跑 29 条 CLI 控制请求，14 个观察点一致。覆盖文本编辑、稳定对象 ID、重排、选区、过期修订拒绝、嵌入图片、撤销重做和分支编辑。另用每版脚本执行 130 次修改和 129 次撤销，确认各版均仅保留最近 128 步。
