# JoyDeck 阶段 3 收尾验证

本批从 `3d30760d` 开始，继续使用 `14cbb296` 冻结 CLI 对照。时间节点按 ECMA-376 的 PresentationML 结构读取和写出。[ECMA-376](https://ecma-international.org/publications-and-standards/standards/ecma-376/) · [PowerPoint 对象动画](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.effect)

- 对象动画从行为节点读取目标，从交互序列的条件读取触发对象。保留主序列、交互序列、动画方向、自动反向、时长、延迟和分段文字生成的契约。写出入口按效果类生成时间节点，复用形状 ID 映射。
- 原生档案序列化将非有限浮点写为零，同时区分可选值缺失。清单、媒体和图表附带部件的写出受到读入预算约束。两套原生入口检查清单版本，旧格式的数值空值仍可修复。
- 原生模型恢复以实际布局标识表核对页面引用，所有主布局缺失时分配可用布局。保留重复标识的首个对象，重新分配能修复的重复项。沿用标识耗尽时保留原对象和限制后续增长的行为。
