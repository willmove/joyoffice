## JoySheet

自动季节识别使用去线性趋势后的自相关和首个显著局部峰值。拟合更新初始水平、趋势和季节项，区分全序列置信区间误差与长序列统计的尾段误差。对样本内小数时间点，使用最终拟合状态和有符号时间距离。常见系数使用有界候选搜索，短季节序列保留已有的初始化和耦合系数路径。

用 Excel 原生强制重算生成参考缓存。类型和错误精确比较，数值相对误差上限为 `1e-9`，绝对误差下限为 `2e-10`。每份工作簿跑了冻结版和候选版四种读写组合，读回均保持各自的计算语义。[用例结果和指纹](sheet-ets.json)

## JoyWord

复合词用显式栈遍历切分并按实际到达状态记忆失败结果。多级词缀按固定顺序归并各标记的规则流，保留访问预算和候选顺序。75 个锁定归档的 1,499 条探针与上版一致，其中 1,179 条有排序建议。专门构造的三段词缀和复合词样本也通过三版本对照。Windows「审阅 → 拼写和语法」接入已有更正命令。原生窗口依次更正两处样本，单步撤销与重做、保存及新进程重开均核对通过，DOCX 正文独立读回一致。同一验证修复了 Windows 调试构建打开审阅时的主线程栈溢出。[校对差分](word-proof.json)
