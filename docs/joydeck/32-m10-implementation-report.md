# M10 动画、放映与PowerPoint界面改进

日期：2026-10-30。本机可代劳的软件开发与验证已持续推进；**M10完整验收仍开放**：当前只有一个有效显示器，不能宣称完成真实双屏、镜像/DPI/热插拔、系统睡眠唤醒及完整AT-12。软件子项、前序回归和未完成项分别记录在任务清单。最终日志/哈希/指标见 [验证索引](evidence/m10/final-verification.json)。

## 确定性播放

Presentation/Timing/Effect持久化在文档；播放步数、时间、暂停、黑白屏、激光和临时墨迹在Controller中。ShowSnapshot不可变，编辑器继续编辑不会改动已开始放映的文稿。模型没有窗口或墙钟，按毫秒确定性采样；原生窗口用Instant驱动。预览和正式放映共用此采样器。

支持出现、淡入/淡出、飞入、移动、缩放和旋转；单击/与上一项同时/上一项之后、持续/延迟、重复、自动反向、倒回和显式段落目标。时长1–60000ms，延迟≤60000ms，重复1–64，单效果展开≤600000ms，每页≤256效果。当前UI重复快捷切换为1/2；模型支持完整预算。按段落限未旋转文本和显式换行，不声称完成自动换行/bidi/逐字动画。

点击先完成当前未结束步骤，再进入下一步骤/页。后退返回上一动画步骤，跨页后退显示上一页末态；显式页跳转重播该页。seek定位当前步骤，不修改原稿或总演示计时；R重新预览，P冻结时钟。超过5秒的原生间隔暂停并提示恢复，不逐帧补播。屏幕消失会暂停，具体平台重定位仍需硬件验证。

观众窗口是唯一时钟拥有者；窗口重建/屏幕选择使用代次移交，旧计时任务停止，避免两个窗口叠加计时。准备、单飞后台渲染与过期视图由实体生命周期隔离；正式保存/导出继续使用既有不可变快照和revision守卫。

## 转场、Morph与格式

无/淡化/推进/擦除有确定性像素合成，前页缓存最多两个、每项≤32MiB（显示缓冲另计）。动态帧1024宽、稳定帧2048宽；时钟约33ms调度，复杂图表可能低于30fps。不是已达成60fps或纯GPU动画的声明。

平滑子集使用显式匹配名，同页重复/空名拒绝；支持同类且内容一致对象的几何/旋转/透明度、同资源图片的裁剪插值。内容、样式、图片资源变化或无匹配时交叉淡化；任意路径/逐字/3D不支持。公开输出使用`!!`对象名与Microsoft Morph扩展及fade回退，其他软件的匹配结果不能保证完全一致。

公共PresentationML输出基础时间树、支持的效果参数、转场和自动换页；读取支持的常见基础树与直线motion路径，未知树给出诊断，原始字节仍保留在源包。测试包含7类效果参数的公共重读、PowerPoint实际生成的500ms淡化导入、JoyDeck输出600ms淡化被PowerPoint正常识别。仅这些实际样例完成本机交换；不能据此声称全部效果的Office视觉往返已验收。内部对象链接/自定义页序/循环在原生格式生效，公开PPTX未输出这些链接/自定义放映设置，导出有明确损失说明。

## 双窗口与工具

演示者视图显示当前采样画面、下一页、独立备注、计时、导航、暂停、定位、观众窗口切换和屏幕选择/交换。备注区有滚动，图像使用受限尺寸与文稿比例，避免2048图像内在尺寸把备注挤出屏幕。GUI发现并修复了此问题和深色窗口内输入值对比度。结束放映后恢复编辑器焦点，避免快捷键失效。

单个有效屏幕使用窗口化观众画面；多个有效屏幕提供目标全屏与交换入口。观众按Tab返回演示者窗口。黑白屏、激光、墨迹、1–9跳转、内部页链接、自定义可见页序、循环/自动换页和排练计时可用。墨迹≤256笔/2048点；退出时可继续、放弃或另存副本，编辑原稿不变。排练计时另存原生副本，不把播放位置作为编辑事务。

真实GUI已验证：预览退出还原、900ms动画保存、演示者键盘推进、观众不含私密备注、黑白屏、红色激光与墨迹、保留/放弃墨迹、排练计时另存。`gui-ink.joydeck`中的线段与`gui-rehearsal.joydeck`的自动翻页时间已经检查，证据与最终演示者截图见 [UI审查](evidence/m10/ui-reference/audit.md)。这证明单屏下双窗口，不是两块物理屏幕。

## UI对照与验证

采用product-design audit流程，实际打开本机PowerPoint，另建原创文稿采集开始/插入/动画/放映参照，未修改用户原有文稿。JoyDeck使用现有Lucide全量资源补齐缺失图标；重构透明标题栏/快速访问/功能区，开始按剪贴板→幻灯片→字体→段落→绘图排序；插入按新页→表格→图片→形状/图示/图表→文字排序。

缩略图宽度和起点、画布纵向起点、备注折叠栏与状态栏按1600×900窗口对照；默认收起格式栏，上下文页签随选择出现。系统字体列表、形状菜单和表格行列数对话框是真实入口；大图标补充名称/提示，增加常用快捷键。不是把所有未实现的PowerPoint按钮画成可用状态，也不是像素级克隆或读屏合规认证。

102项软件测试覆盖时间线、repeat/rewind、暂停/seek、目标清理及undo、段落、Morph几何/裁剪、转场边界、页序/循环/排练/链接、原生与PPTX参数和无效预算。原生窗口测试另外验证实际时钟、暂停、黑白屏、导航、窗口移交唯一时钟、快照不变和编辑器焦点恢复。最终包执行M0–M8、M9/M10和系统拼音回归通过；图表画布GPUI/CPU平均RGB误差分别0.184/0.428，原生复杂图表准备p95 35.142ms（31帧），时钟移交220ms单时钟检查通过。CI配置更新到M10，不等于远端CI已执行。末轮CUA连接默认编辑器/原生文件对话框Raise超时，正常绘制截图与AppKit事件循环采样已留存；这次额外编辑器导入不算人工通过，实际可视查看器重读133及原生导入adapter通过，详见UI审查。

BENCH-SHOW固定30页、每页20对象/5效果、600次CPU帧采样；独立记录p50/p95/max。原生复杂图表另记录渲染任务准备耗时。实测CPU帧p50 0.550ms、p95 0.627ms、max 0.791ms，见 [原始基准](evidence/m10/authoring-delivery/BENCH-SHOW.json)。CPU离线帧时间、原生渲染准备耗时与实际显示帧率分开；不将其换算为已达成端到端60fps。
