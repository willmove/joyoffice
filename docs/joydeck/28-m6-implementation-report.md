# M6 文稿设计增量与前序收尾（2026-10-30）

本轮交付 **M6 文稿设计开发预览**。实现了以下可运行纵向增量，完整M6及AT-09/05/14保持开放；M0–M5的未关闭退出条件未被转移或豁免。

## 实际实现

### T-M6-01a：同文稿共享写入者和历史

新增无GPUI依赖的SharedSession：一个Mutex保护的Session拥有文档、undo/redo和保存基线，窗口持独立不可变快照/选择/当前页/手势/文本输入状态。顶部提供“同文稿新窗口”和“新文稿窗口”。前者共享历史与文件指纹，后者独立；约100ms轮询共享revision并按页ID保持当前页，不复制另一窗口选择。过期窗口写入被拒绝，远端修改取消未提交画布文字与手势草稿，避免旧草稿覆盖。后台scene/CPU/媒体/文件结果在发布前同步文稿身份/revision。

保存使用共享RAII租约串行化；一个窗口保存旧revision成功后，如果另一窗口已编辑，文稿仍dirty。租约随异步任务释放；共享文件路径/指纹供其他视图继续保存。每窗口保留独立恢复日志，保存后的同步视图清理自身旧日志。显式同文稿窗口已连接；独立重开同文件不自动合并Session，仍靠指纹冲突保护。多文档标签/完整ViewSession类型抽离和所有关闭/恢复矩阵尚未完成。

### T-M6-02a/03a/04a：主题、母版、版式与文字占位符

design.rs新增主题/母版/版式ID表与Layer。kind/index匹配文字占位符，解析顺序为对象基值→母版→版式→direct覆盖。主题颜色/字体用@slot存储，CPU预览、Scene、缩略图均由同一解析器消费；解析后的RGB不写回持久模型。格式/几何修改通过直接覆盖保存，主题修改更新继承对象而保留直接颜色；应用/重置版式保留对象ID和文字。重置清除direct与富文本直接样式；不匹配的新旧占位符保留为普通文字并保留解析后的外观。

“文稿设计”右侧面板提供原创默认设计、复制/重命名母版及版式、主题accent/正文字体/纯色背景、母版标题字号、添加页码/日期占位符、应用与重置。删除在用版式必须在领域命令提供替代或拒绝；UI目前采用拒绝。删除仍被版式引用的母版也拒绝。无悬空master/layout/theme或非法槽位。界面支持的母版编辑范围仅为上述属性，不是完整母版画布编辑器；图片/非文字占位符未实现。

### T-M6-06a/07a：文稿文字与组织

- 页码按页序、日期按固定fieldDate解析；相同文档快照不依赖render时系统时钟，跨文档后使用目标上下文。日期不是自动更新的系统时间。字段暂不开放画布直接输入，防止解析值反写覆盖字段模型。
- 区分大小写的文字查找、定位页与选区、全局替换（一次undo）；UTF-8字节范围安全，≤10000匹配，超限整次拒绝。继承文本未格式化时替换保留空runs，避免把主题样式意外固化。字体替换覆盖主题字体、显式Layer和runs，一次undo。
- 文稿标题、作者、主题说明、固定日期，多行当前页备注；节创建/重命名、选中页归节、删除节保留页面；大纲导航点击后沿用有效页面/焦点路径。
- 备注草稿需“应用”提交；绑定页面ID和载入时备注值，切页自动刷新，远端改过备注时拒绝旧草稿，提供刷新字段按钮。未应用的面板草稿不会持久化。新建页清空备注和节，避免复制第一页私有备注；复制页正常保留备注。

### T-M6-08a：跨文档页面快照

PageTransfer v1自持所选页面、设计、节和图片资源，可在源会话销毁后粘贴。重新生成页/对象/主题/母版/版式/节ID；同哈希媒体共享，undo撤回时当前快照回收未引用媒体。提供保留源格式、使用目标文稿首个主题两种入口；后者缺少源设计所需槽位时整次拒绝。跨页尺寸按横纵比例缩放几何，字号按较小比例缩放；描边等并非完整仿射格式变换，不宣称所有非均匀缩放保真。动态字段使用目标上下文。

剪贴板JSON≤8 MiB，原有模型/历史/页数/资源预算继续适用。普通对象剪贴板会固化源继承外观、解除binding/field，以防粘到无设计目标后悬空；这也补上M5与新设计模型之间的兼容收尾。
