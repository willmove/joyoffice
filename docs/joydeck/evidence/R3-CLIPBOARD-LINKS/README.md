# JD-307 剪贴板链接范围

2026-11-05，Apple M4／macOS 27.2，1× 实屏。使用仓库外解压的 ARM64 Release 验收包 `joydeck-0.8.0-r3-clipboard-links-scoped.zip`，1,805 项载荷散列一致。归档 SHA-256 为 `e5613ba7ccb03cd3ec48550242e8e567400470dfbe969d95de588972f94d403c`。[源文稿](scoped-source.pptx) · [目标文稿](scoped-destination.pptx) · [验证数据](verification.json)

通过系统剪贴板复制富文字或对象时，应用记录当前编辑会话的随机标记。共用同一编辑会话的窗口保留仍有效的页内动作。跨文稿、重新打开后的旧剪贴板以及来源不明的旧对象数据保留文字、字符格式和可移植的链接，同时移除无法解析的页内引用。涉及移除时状态栏会提示。快捷键和菜单共用处理路径。[修复前的页 ID 碰撞复现](../R3-CLIPBOARD/README.md)

| 路径 | 实测结果 |
| --- | --- |
| 同文稿双窗口 | Cmd+C 复制带粗体、页内点击／悬停和网页链接的文字。在同一文稿的新窗口用 Cmd+V 粘到第二个文本框，原有动作和格式保持，原窗口读到修订 1。[双窗口](01-shared-view-before.png) · [粘贴结果](02-shared-view-linked-text.png) |
| 同文稿对象 | 复制并粘贴带形状点击动作和链接文字的对象。另存后独立读取原生模型，确认形状及文字仍链接到源文稿的第 2 页。[对象结果](03-same-document-object.png) |
| 跨文稿富文字 | 将同一剪贴板内容粘进独立进程的目标文稿。粗体和网页地址保留，页内点击与悬停链接移除。一次撤销恢复原文，一次重做恢复粘贴结果。[跨文稿文字](04-cross-document-text.png) |
| 跨文稿对象及重开 | 两份文稿的第 2 页模型 ID 均为 11，内容不同。复制对象后，目标模型没有源形状点击动作，网页链接和字重保持。独立读取原生包后，在新进程重开并核对两处结果。两个输入 PPTX 散列保持。[跨文稿对象](05-cross-document-object.png) · [独立重开](06-reopened-destination.png) |
| 旧剪贴板 | 从上一个 Release 复制对象，当前版本读取旧数据并粘贴。保留文字和网页地址，移除旧数据中来源未确认的页内动作。[旧数据粘贴](07-legacy-object-paste.png) |

新增回归覆盖页目标有效性、跨文稿的粗体和网页链接、无法解析的链接声音，以及移除链接后仅被该链接引用的对象资源。JoyDeck 产品检查 921 项通过，0 失败、0 忽略。 三产品联合验证通过 5,821 项。包内 CLI 通过 R1、R2、R3、R4/R5 的 28、20、20、23 项复验和 329 条命令注册表核对。 同一包还复验系统纯文本、内部富文字、图片和表格对象、外部 PNG、单步撤销、失败剪切及 PPTX 图片复用。

JD-307 仍开放。跨文稿富文字图片格式缺少可移植资源时会给出提示，可通过复制整个受支持对象携带媒体。外部 HTML／RTF 和完整 Office 对象交换继续跟踪。
