# JoyDeck R2 手势与基础编辑复验

2026-11-05，Apple M4、macOS ARM64。通过产品命令生成 Release 验证包，在仓库外含中文和空格的路径解压启动。实际窗口由 macOS 鼠标和键盘事件驱动。附加控制端用于读取实时模型、修订、选择、撤销栈和脏状态。

## JD-202 手势

- [原始验收脚本输入](seed.json)由包内 CLI 生成 v2 文稿，含重叠的矩形与椭圆、45° 矩形和独立矩形。点击椭圆、点击椭圆外接框空角、Shift 加选和移除、框选与 Shift 追加框选均按预期更新稳定对象 ID。旋转矩形外接框的空角既不会被点击选中，也不会被小框选命中。[多选截图](01-marquee.png)
- [旋转选择手柄](02-rotated-grips.png)与对象同向。缩小后拖动对角手柄时，模型宽度增加约 40 pt、高度减少约 20 pt，对角锚点保持在舍入误差范围内。Shift 旋转绕原中心从 45° 到 135°。拖动只提交一个编辑，撤销回到干净文稿，重做恢复相同变换。[缩放截图](05-rotated-resize.png) · [旋转截图](06-shift-rotation.png)
- [拖动预览](03-drag-preview.png)期间，控制端明确报告手势进行中。按住拖动和框选时，Esc 在释放鼠标前取消手势。切换到 Finder 后再释放也保留文稿内容和原修订。画布外移动和释放由窗口捕获，两个选中的对象同时移动，单次撤销恢复两者。在编辑器外框右侧 16 个逻辑像素处释放，原窗口也能收到结束事件并单次提交。源 v2 文件 SHA-256 保持一致。[取消截图](04-escape-cancel.png) · [画布外拖动](07-captured-outside-slide.png)

当前显示器仅枚举 1920 × 1080、1× 模式。真实窗口验证覆盖约 99% 与 74% 的画布缩放；旋转锚点和命中半径的自动回归覆盖四档逻辑缩放。JD-202 保留为已实现待验收，需用 2× Retina/HiDPI 显示模式复跑同一手势场景。Windows 和 Linux 原生窗口在本轮未复验。

## JD-203 基础编辑

在同一实际窗口从原生菜单新建空白文稿并插入新页。用形状图库插入矩形和椭圆，下移及上移一层后，实际对象顺序相应变化。创建副本分配新对象 ID，画布命中该副本，系统 Delete 删除，原生菜单撤销恢复同一 ID 和选择。移动、缩放和旋转见 JD-202 场景。[新建与副本](08-basic-edit.png) · [撤销删除](09-undo-delete.png)

## 构建与核对

- `cargo xtask check joydeck` 共 902 项通过，失败与忽略均为 0，包含导入来源、依赖、格式及严格 Clippy 门禁。
- `cargo xtask package joydeck --release --validation --name joydeck-0.8.0-verified-pointer` 生成 Release 验证包。解压后核对 1,805 项 payload SHA-256。
- 同一包内的 CLI 通过 R1 28 项、R2 20 项及 329 条上游命令注册核对。R2 包括强制退出及恢复。
- 二进制、源快照、包、样例和截图指纹见 [验证数据](verification.json)。
