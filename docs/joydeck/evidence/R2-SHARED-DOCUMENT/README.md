# JoyDeck R2 共享文稿与独立视图验收

2026-11-05，从 `4a9dd9b` 构建 Apple M4／macOS 27.2 的 ARM64 Release 验收包。包移到仓库外的中文空格路径，归档与包内 1,805 项散列核对一致。[源码、产物和结果指纹](verification.json)

## JD-201 实现

- 在「视图」使用「新建文稿视图」，两个窗口引用同一份 shell `Editor` 和引擎 `Session`。不同窗口打开同一个规范化源路径时也加入现有文稿。
- 窗口各自持有只读模型快照和选择，缩放、页轨、焦点和视图控件各自更新。其他窗口重排时按稳定页 ID 保留当前页，仅保留仍存在的对象选区。
- 修改、撤销历史、保存指纹、未保存状态和恢复检查点由共享文稿维护。关掉仍有其他视图的窗口会保留该文稿与未保存修改，最后一个视图继续使用保存提示。
- 更新文稿时通知各窗口刷新缓存。过期的文件读取、编辑预检、图片、比较及恢复结果继续按文稿代次、修订和对应选择校验。
