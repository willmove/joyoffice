# JD-305 批量更新已有页脚文字

2026-11-06，基于主干 `7b37ad4c884706087983d352d4a11148040de02a`。本批仅引擎命令及自动回归，没有新增桌面 UI；与页脚导入摘要修复分支独立。

## 命令范围

新增 `Command::SetExistingFooterText`，走现有 `Session` 快照、预检、预算、撤销／重做和原生 JSON 命令解析路径。命令对象示例：

```json
{"command":"set-existing-footer-text","text":"统一页脚 中文😀"}
```

它遍历全部幻灯片，更新页内已有、未锁定且可见的普通页脚占位符。没有页脚的页面保持不变，不从母版新建页脚；页码、固定／自动日期、页眉、其他形状、标题页布局保持不变。各页形状 ID、位置、字符和段落样式、正文框属性保留，只统一明确指定的页脚文字。更新文稿摘要中的页脚启用状态和文字；不是仅修改摘要。

初始支持单段、零个或一个普通文字 run 的页脚。遇到分组、锁定、隐藏、非普通文本、多个段落／run 或字段页脚，整次操作报错，提示逐个编辑；不静默跳过或压平内容。输入限单行 64 KiB，整次最多 256 个占位符、1 MiB 新文字。空字符串清空文字但保留占位符。没有页脚时明确报错，不把未执行操作描述为成功。

原始逐页文字随一次 Undo 恢复，Redo 重做；重复同一值无新修订。选择和当前页不变。复杂页脚可在未来扩展，但本批不通过丢失其格式来模拟支持。

## 自动回归范围

- 引擎：两页不同文字／字号／字重和第三页无页脚；JSON 命令执行、保留页内差异、选择不变、单次修订、重复无操作、单步撤销／重做。
- 原子拒绝：第二页锁定、隐藏、混合 runs、动态字段、分组页脚，以及缺少页脚、控制字符、输入过长、目标数／输出预算超限；前面页面、保存标志和历史不变。
- Shell：两个页脚页和一个无页脚页，每页带动态日期；执行后保存原生格式和 `export_preserving` PPTX。原生模型完整相等；PPTX 重开只改变指定页脚文字，各页样式和日期字段保持；无页脚的第三页 XML 原始字节不变，并验证 Undo／Redo。
