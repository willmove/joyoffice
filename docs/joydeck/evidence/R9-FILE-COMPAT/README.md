# JoyDeck R9 文件流程与旧控制复验

2026-11-05 从 `099bce4` 开始，在 Apple M4、macOS 27.2 上验证。以下按实际构建与复验范围记录，R0–R9 的阶段验收继续按任务表收口。

| 工作项 | 已完成范围 |
| --- | --- |
| JD-206／801，原生另存 | macOS 给原生面板提供无扩展名的建议，建议名称中的点用全角点显示，避免面板把源名称的最后一段当作固定后缀。确认后将面板返回的路径直接交给保存作业，用户未指定后缀时仍使用 `.joydeck`。 |
| JD-706／906，旧控制 | 旧批处理在临时快照上逐项解析和应用，后续页索引基于上一步的结果。全部步骤通过后才由当前会话单次提交。旧表格字符串 ID 按所在页的迁移标记解析，保留数字 ID；重复旧标记和越界页明确拒绝。 |
| JD-506／906，比较与接受 | 两份文稿的稳定页 ID 唯一且集合一致时，按 ID 比较重排后的对应页。页序差异独立报告，接受对象修改时取对应参考页并继续校验双摘要。ID 集合不同的文稿继续按页序比较。 |

## 自动回归和开发包

`cargo xtask check joydeck` 的格式、严格 Clippy、依赖隔离、291 项来源指纹及 898 项测试通过。新测试覆盖原生另存建议、批次原子提交和单次撤销、迁移表格 ID 与越界、重排后对象接受和撤销。

`cargo test --workspace --locked --features joydeck/validation,joysheet/automation` 联合回归 5,790 项通过、0 失败、3 项忽略。忽略项是 Sheet 计时基准、Word 恢复格式体积测量和需要本机授权楷体的轮廓测试。

`cargo xtask package joydeck --release --validation --name joydeck-0.8.0-r9-closeout` 生成 macOS ARM64 验收开发包。归档和包内 1,805 项校验通过。将 Release App 解包到仓库外中文空格路径后，包内 CLI 完成 R1–R7 的 124 次调用和 43 次 MCP 响应检查。另以包内 `control` 验证旧批次预检无副作用、失败保持原状、成功另存后读回重排页备注，以及一次撤销恢复为一页。[归档、源码和二进制散列](verification.json)

## 实屏复验

- 用带点的中文源文件名调用原生「另存为」，取消无输出。逐一输入 `.pptx`、`.joydeck`、无后缀和带点的大写 `.PPTX`，四个目标均按预期落盘。包内 CLI 和独立 ZIP/XML 或 manifest 均读回三页，原件散列一致。
- 同一二进制通过 LaunchServices 冷启动与运行中打开、重复打开、坏文件后恢复、文件／编辑菜单、撤销／重做和未保存保护。[逐项结果](verification.json)

JD-104 的运行中取消和迟到请求专项、JD-206 的文件冲突与并发保存完整矩阵、JD-506/706/906 的复杂文稿和旧控制全量兼容继续开放。Windows、Linux 和其他 macOS 版本的当次实屏验收仍待执行。开发包的 5 个许可缺口与正式发行资格留在 JD-807/808。
