# JoyDeck R1 打开请求与文稿修订复验

2026-11-05 从 `69880cc` 开始。macOS 27.2 / Apple M4，使用移到仓库外中文空格路径的 ARM64 Release 验收包。归档和包内 1,805 项 SHA-256 校验通过。[包、源码、运行时及测试指纹](verification.json)

- **JD-104**。读取请求与已打开文稿分别维护代次。取消信号传入分块文件读取、散列、ZIP 部件检查和格式迁移边界，单次系统读取或格式库调用返回后继续检查。保存指纹对应实际解析的字节。只有接受新文稿后才切换会话、取消旧文稿的导出并登记最近文件。
- 实际打开一份 18,015 对象的有效 PPTX，进入后台读取后点击状态栏「取消打开」。原文稿及其桌面控制 ID、修订与最近文件保留。随后用新的 LaunchServices 请求取代正在读取的请求，新文稿有独立 ID，旧结果未被安装或写入最近文件。按键注入未稳定触发 Esc，本次运行中取消证据来自状态栏按钮。
- 在当前文稿插入一页后取消原生文件选择器，随后对损坏 PPTX 选择「不保存」。两次均保留当前文稿。坏文件失败后，窗口仍有四页和未保存标记，控制端 ID、修订、选择与撤销状态一致，恢复记录散列不变。撤销后回到三页，输入文件散列一致。[实际窗口](dirty-after-bad-open.png)
- **JD-106**。同一包的 CLI 完成 R1 的 28 次实测调用，覆盖 PPTX 与 DeckCraft 语义读取、PNG 尺寸、拒绝覆盖、非法参数和输入散列不变。CLI `commands` 读出共享引擎的 28 个类型化入口。锁定的 CLI normal/build 依赖闭包通过隔离检查。329 个上游命令的对应和支持范围继续由 JD-107/509 验收。

`cargo xtask check joydeck` 通过格式、严格 Clippy、依赖隔离、291 条来源记录及 899 项测试。系统打开冷／热启动、重复打开、坏文件、菜单与未保存保护共 7 项实屏回归通过。

本次实屏证据覆盖 macOS ARM64。Windows 和 Linux 的桌面资格继续由相应平台任务记录。开发包未正式签名，许可缺口仍由 JD-807/808 跟踪。
