# JoyDeck JD-208 常用命令状态复验

2026-11-05，Apple M4、macOS ARM64。使用仓库外中文空格路径中的 Release App 和同包 CLI。样例由 [手势验收脚本输入](../R2-POINTER/seed.json)生成。实际操作经 macOS 键盘、鼠标和原生菜单执行，附加控制端读取窗口内模型。独立的包内 CLI 控制进程按相同选择和命令复现，逐步比较对象 ID、层级、页序、文稿修订和撤销状态。

| 场景 | 结果 |
| --- | --- |
| 一页、无选择、无历史 | 原生菜单和 Ribbon 禁用删除最后一页、创建对象副本和层级操作，快速访问撤销和重做也禁用。CLI 预检返回对应错误或无变更。 [初始状态](01-clean-command-state.png) |
| 无选择按 Delete | 状态栏显示「请先选择对象」，模型修订仍为 0，未产生脏状态。[状态提示](02-disabled-shortcut-reason.png) |
| 选中顶层对象 | 上移禁用、下移启用。菜单下移后，上移菜单与 Ribbon 启用，点击 Ribbon 上移恢复原层级。CLI 预检与实际对象次序一致。[层级边界](03-layer-boundary.png) |
| 对象副本和撤销历史 | 快捷键创建新对象 ID，菜单删除与撤销，快捷键重做。CLI 与窗口选择、修订、模型和历史一致。重做后按钮和菜单禁用。 |
| 复制与删除幻灯片 | 原生菜单复制得到第二页。Ribbon 删除后恢复一页，最后一页删除重新禁用。[最后一页保护](04-last-slide-protected.png) |
| 保存 | 使用原生菜单保存，修订保持不变且脏标记清除。包内 CLI 独立读回同一页序、四个对象及其 ID、层级和几何。[保存后](05-native-save.png) |

预检与执行共用引擎的事务准备和预算检查。窗口按修订和选择缓存预检结果，多窗口文稿仍以各自选择计算。自动回归另覆盖锁定对象和预检无副作用。选择、工具栏和对话框均通过已有引擎命令或文件服务提交。

`cargo xtask check joydeck` 通过 903 项测试和格式、严格 Clippy、依赖及来源门禁。用 `cargo xtask package joydeck --release --validation --name joydeck-0.8.0-command-state` 打包，解压后核对 1,805 项文件 SHA-256。同包 CLI 通过 R1 28 项、R2 20 项、R3 20 项及 329 条命令注册对照。验证明细及指纹见 [数据](verification.json)。

JD-208 覆盖 R2 常用编辑入口。完整 Ribbon/图库继续由 JD-508 跟踪，其他平台窗口和高 DPI 实屏按 JD-804 与 JD-202 记录。
