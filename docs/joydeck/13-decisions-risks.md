## 4 默认假设和需要补齐的条件

当前目录包含 JoyDeck 独立实现及文档。产品默认离线、简中与英文、Windows优先开发且核心三平台发布。

当前工作目录没有 Git 元数据。回退依靠保留的 M0 分发包与阶段快照；构建和运行证据见 15。

后续需要逐步取得：macOS/Linux实际测试环境，授权外部PPTX语料与可记录的PowerPoint版本，合法可分发字体，正式签名/公证凭据。可先用开发包、合成语料和已具备平台完成独立工作；缺失条件不能通过文档勾选消除。

是否开源、最终品牌/MIME、具体安装器、更多语言、额外格式/云服务优先级可以后续确定，不阻挡M0–M3。涉及已授权范围内的可逆实现按本规格推进；新外部付费服务或不可获得的账户/硬件必须如实说明条件。

## 5 范围变更流程

新增能力先写用户价值和FR，映射任务/阶段/AT，再决定替换或增加工作量。修改核心不变量需更新ADR。若某阶段退出条件未达，状态保留进行中并交付可运行诊断/fallback，不能通过删掉失败验收把它标完成。

估算在M0、M4、M7、M11后复议：分别依据依赖/输入风险、GPU结果、真实文件兼容和媒体平台结果。风险缓冲用于未知实现难度，不作为放弃必要质量门槛的理由。

## 2026-10-29 M2剩余实现决策

ADR-016：稳定对象ID、旋转/样式/隐藏页写入minor1，minReader2与必需特性防止旧读取器误读；支持minor0升级。

ADR-017：保存恢复补齐当前文件指纹检查、其他目标确认覆盖、等待保存/放弃清理后关闭。恢复采用标准库文件锁、1秒空闲/60秒上限、每会话3份与逻辑1GiB预算；预算含隔离/旧版文件，不能安全清理时停止追加并报告。旧版无租约缓存不自动删除。ADR-015的新路径限定是初始切片历史，当前契约以22为准。

ADR-018：M2原生容器和编辑器保持至少一页，拒绝删除全部/末页；以11已有末页保护及v1不变量统一03中相冲突的零页表述，不支持零页持久化。

ADR-019：100步/32MiB为当前M2历史预算，计入undo与redo的序列化估算，采用缓存字节计数；不是RSS约束或Beta最终预算。完整人工/平台验收仍未关闭。

## 2026-10-30 M4 后端决策与风险复核

- ADR-004：现有模型采用窗口无关 Scene + GPUI path/image + 同源逐 glyph mask；局部效果按隔离对象 CPU raster。release 与像素/RSS 结果见 [26](26-m4-implementation-report.md)，方法见 [25](25-m4-scene-validation.md)。不新增图形依赖或假定跨 device 零拷贝。
- 静态文字沿用 SVG shaper 的 glyph ID/轮廓/位置，16 个亚像素相位共用一张字形纹理。首轮整段轮廓逐帧复制方案虽延迟达标，却有约 2.7 GiB RSS，已淘汰；最终需同时满足像素、延迟与 RSS 门槛。
- GPUI 边界显式转换 premultiplied RGBA → straight BGRA。图片加透明保护边，在设备整像素 quad 内按原图坐标裁剪，防止上游 paint_image 的 bounds 吸附造成小数位置拉伸；高反差独立图像复测后保留原阈值。
- 派生资源不进入文档，按窗口/scale/DPI 缓存，LRU/文本 shaping 前限额/任务取消与身份检查限制分配与迟到结果；释放 RenderImage 时显式移除 atlas 条目。适配器估算缓存数值不代表框架 RSS 或 driver VRAM。
- 公开 GPUI 未提供应用可用的完整 device-lost 注入/恢复回调。CPU 内容切换与缓存重建已验证，真实设备故障仍开放，不能将两者等同；Windows/Linux、跨屏/长期/多窗口预算需另取证据。
- ADR-005 未关闭：M3 活动文本编辑仍有独立布局，静态 Scene 与 CPU 同源不能替代完整编辑排版与输入验收。完整 M4 的前置条件和 AT-07/15 保持开放。

## 2026-10-30 M5 图片资源决策

- schema1.3/minReader4新增image-resource-v1；SHA-256命名PNG独立部件。导入应用EXIF并规范化，不保存原编码元数据；crop只保存归一化区域。旧reader明确拒绝，不静默丢图片；开发前源码及M4包保留。
- 资源按Arc共享并随事务做引用回收，历史/transfer独立自持资源。当前历史JSON估算保守且包含资源，可能早于32 MiB资源总预算拒绝。validate存在重复解码/hash成本，仍需性能/长期压力优化，不能冒充已完成资源预算闭环。
- 图片优先复用现有局部对象raster fallback保证CPU/Scene同数据，未实现直接源纹理路径。受限SVG/metafile、组/连接符/锁定与高级路径没有因UI接线完成而豁免。
- 系统剪贴板由GPUI平台adapter提供，已做macOS真实OS读写集成；Windows/Linux及物理拖放待验收。内部v1 payload带独立资源及对象，保留plain文字fallback，外部rich HTML/RTF未实现。
- 本轮前序工作为M0–M4回归和数据安全扩展测试；统一文字布局/真实device-lost/跨屏与完整平台人工验收等软件或硬件缺口继续保留，见27。

## 2026-10-30 M6 文稿设计与共享会话决策

- 原生schema1.4/minReader5新增design-v1，保存主题/母版/版式/文字占位符与direct覆盖、页备注/节、文档属性与固定日期字段上下文；旧1.0–1.3仍读，旧reader拒绝新文件。CPU与Scene使用同一设计解析器，主题槽位保留为引用，不将解析RGB写回原模型。
- SharedSession持有单个受Mutex保护的Session写入者/历史；Editor只持不可变快照与独立选择/页/手势/输入状态。约100ms检测共享revision，拒绝过期写入，远端变更取消未提交画布草稿；保存共享租约以RAII释放。既有后台结果在发布前同步文档身份/revision。每窗口仍有独立恢复日志，不声称多窗口恢复UI已完整验收。
- 跨文档页快照自持设计和媒体，页/对象/主题/母版/版式/节ID重新映射；目标主题缺槽整次拒绝。不同页面尺寸做显式比例转换；字号/边框等并非任意非均匀缩放的完全保真模型，具体范围见28。普通对象复制固化源外观并解除占位符引用，避免将M6依赖泄漏到M5对象剪贴板。
- 固定日期由文档fieldDate提供；动态页码按页面序号解析，跨文档后使用目标上下文，不依赖每次render的系统时钟。完整autofit/链接/字段与PPTX母版往返没有据此关闭。
- 备注是显式提交的多行草稿，绑定页面ID及载入时备注值；切页刷新，其他窗口修改后拒绝旧草稿覆盖。完整双语资源、读屏、三平台与完整AT-09/05/14继续开放。详见28。

## 2026-10-30 M7 文件交换与输出决策

- schema1.5/minReader6保存源PPTX package sidecar，按部件保留原始字节与关系闭包；文字映射严格核对XML文本节点，非子集修改拒绝。复制/删除任意未知对象的关系重映射尚未实现。
- 独立PPTX writer输出静态公共对象，专有快照受公共包hash约束；外部修改失效后使用公共导入，不能以原生快照自循环测试证明外部C2。40份原创合成样本另用python-pptx读取公共内容；≥5授权外部语料仍缺。
