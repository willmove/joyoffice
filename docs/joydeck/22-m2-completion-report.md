# M2 剩余实现与 Windows 验证记录

2026-10-29（Asia/Shanghai）。本轮补齐 M2 交互、保存和恢复实现，并通过 Windows 自动/原生窗口验证。**功能实施完成与完整里程碑验收分开记录**：T-M2-01～09 的本机实施完成，T-M2-10 的完整人工/平台验收保留未勾选。M0/M1未测项未据此关闭。21是初始切片的历史记录。

## 交互与编辑事务

- 画布实际使用鼠标按下/移动/释放处理器：点击、Ctrl/Shift多选、框选、拖动、八点缩放、旋转；Shift移动约束轴、等比缩放和15度旋转吸附，Alt中心缩放。已有旋转的选区使用等比缩放，避免模型无法表达的剪切。
- 每次移动从手势前的对象快照计算预览；释放后一次提交，Esc/失活/移出窗口释放取消。取消立即恢复原图，不等待新的CPU图像。后台预览合并到一个在途任务，迟到结果按文档/视觉版本/页过滤。
- 页面缩略图为虚拟列表，渐进后台渲染且缓存最多32张；支持Ctrl/Shift多选、拖动重排、按钮上下移动、批量复制/删除/隐藏。对象列表支持多选、置顶/置底和批量删除；重排保持内部相对顺序。
- 圆角矩形和箭头补齐；位置、尺寸、旋转、实色、描边、透明度、纯文字和页面尺寸可编辑。混合值留空保持原属性，单次属性应用是一个事务。
- 稳定对象ID；复制页生成新对象ID，移动与撤销保持ID；复合命令失败不发布半份文稿。历史记账同时覆盖undo/redo，最多100步、32 MiB序列化估算，缓存字节数避免每次重算整段历史。此预算不是应用RSS上限。

## 文件与恢复

原生输出使用schemaMajor=1/schemaMinor=1/minReader=2，requiredFeatures含object-transform-v1，资源索引目前为空。读取major1/minor0并补齐对象ID；未知字段、版本、必需特性和额外资源仍拒绝编辑，不静默丢弃。旧读取器会拒绝新文稿。

保存使用稳定快照，后台写同目录临时文件并sync后提交。新路径用硬链接拒绝意外覆盖；当前文件使用SHA256/长度指纹，在准备前和替换前检查。其他已有目标必须确认覆盖；检测到外部修改时保留原文件并要求重新打开或另存。新文件提交需要支持同卷硬链接，失败有明确错误。检查与rename之间仍有平台级竞争窗口，不宣称文件系统CAS或任意介质断电安全。

保存后只标记实际写入的快照，后续编辑仍dirty。关闭提供保存后关闭、放弃、取消；保存失败/后来又有修改则保留窗口。放弃关闭等待恢复清理完成；清理后若又有新修改，同样保留窗口。从只读窗口退出会激活有未保存修改的编辑器并显示保护对话框。

恢复在提交后空闲1秒写入，连续提交最多60秒触发；不包含属性草稿和未完成手势。记录源路径、指纹、版本、会话与revision。每会话最多3份，恢复目录逻辑字节预算1 GiB，含旧版和隔离文件；无可安全清理项时明确报错并停止追加。使用标准库文件锁，其他活跃实例的快照不可恢复或删除。恢复列表使用虚拟列表，列出有效/占用/损坏项；坏快照及坏索引隔离。恢复为dirty副本并清空保存路径；不自动写回源文件。旧版无锁快照仅只读导入并保留原件。

恢复后的当前及来源记录只在明确保存或放弃时清理；Undo回到已保存状态停止待写任务，不擅自删除旧分支恢复记录。自动化smoke使用独立临时恢复目录，不混入用户正常恢复目录。
