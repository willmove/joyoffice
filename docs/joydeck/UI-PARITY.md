# JoyDeck 界面与功能对照

2026-11-03，主参照为本机 DeckCraft 0.14.1；PowerPoint 用于中文菜单、保存和基础编辑习惯核对。技术栈保持 JoyOffice 的 GPUI Kit 0.8.1 / GPUI pre 0.3.10。没有复制微软图标、品牌素材或系统字体。

## 原因与验收修正

R1–R7 主要交付文稿引擎、格式与平台能力的纵向验证，把路径输入和诊断按钮当成了日常工作区，未执行参照产品的布局与完整工作流验收。因此“后端能运行”与“用户能正常编辑”的差距被低估。过去的编译、样例测试和截图不能证明产品界面已完成。

后续 UI 改动须先观察真实产品，再实现、构建、通过真实窗口操作并对照截图；功能入口必须对应真实命令。保留 329 条命令清单的原始含义，不以新 Ribbon 上的按钮数量代替覆盖数。

## 本轮现场基线

1. DeckCraft 开始界面：标题栏/快速访问 36px、标签约 30px、白色圆角功能区约 78px、左栏约 236px、橙色选页边框、灰色居中画布、底部备注与缩放。[截图](evidence/R8/reference/01-deckcraft-home.jpg)
2. PowerPoint 空白文稿：分组 Ribbon、占位符、系统文件流程、备注和视图/缩放位置。[截图](evidence/R8/reference/02-powerpoint-home.jpg)
3. DeckCraft 插入页：大图标、功能分组和统一控件密度。[截图](evidence/R8/reference/03-deckcraft-insert.jpg)
4. 旧 JoyDeck 实测：多排路径/验证按钮、常开工程属性侧栏、画布空间被挤占，操作不符合参照。属于需要重做的主编辑流程。[截图](evidence/R8/reference/04-joydeck-before.jpg)

5. 同一 PPTX 的主界面对照：[DeckCraft](evidence/R8/reference/05-deckcraft-same-pptx.jpg)、[最终 JoyDeck](evidence/R8/gui/25-final-editor.jpg)。布局已接近，完整功能与控件状态尚有下表差项。

## R9-UI1 后续切片

2026-11-03：在 JoyOffice 内现场复查 DeckCraft 0.14.1 与本机 PowerPoint 中文界面。字体改为 GPUI Kit 可搜索已安装字体列表；字号使用独立常用值/自定义选择、增大/减小及 Ctrl+Shift+./,；颜色使用主题/标准色块、当前颜色指示和自定义六位 RGB。主题色存为 scheme 引用，保留跟随主题的能力。每项仍进入原有 text transaction；完整字体环境/混合格式指示/所有字符格式、最近文件/模板、审阅和其他差项继续保留。最终包已实测 Windows 标点归一化修复后的字号快捷键、Undo/Redo、PPTX 原生另存/独立读回/重启重开；证据为 gui/12–23。详见 [本轮证据](evidence/R9-UI1/README.md)。
