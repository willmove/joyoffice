# JoyDeck 界面与功能对照

2026-11-03，主参照为本机 DeckCraft 0.14.1；PowerPoint 用于中文菜单、保存和基础编辑习惯核对。技术栈保持 JoyOffice 的 GPUI Kit 0.8.1 / GPUI pre 0.3.10。没有复制微软图标、品牌素材或系统字体。

## 原因与验收修正

R1–R7 主要交付文稿引擎、格式与平台能力的纵向验证，把路径输入和诊断按钮当成了日常工作区，未执行参照产品的布局与完整工作流验收。因此“后端能运行”与“用户能正常编辑”的差距被低估。过去的编译、样例测试和截图不能证明产品界面已完成。

后续 UI 改动须先观察真实产品，再实现、构建、通过真实窗口操作并对照截图；功能入口必须对应真实命令。保留 329 条命令清单的原始含义，不以新 Ribbon 上的按钮数量代替覆盖数。

## 本轮现场基线

1. DeckCraft 开始界面：标题栏/快速访问 36px、标签约 30px、白色圆角功能区约 78px、左栏约 236px、橙色选页边框、灰色居中画布、底部备注与缩放。[截图](evidence/R8/reference/01-deckcraft-home.jpg)
2. PowerPoint 空白文稿：分组 Ribbon、占位符、系统文件流程、备注和视图/缩放位置。[截图](evidence/R8/reference/02-powerpoint-home.jpg)
3. DeckCraft 插入页：大图标、功能分组和统一控件密度。[截图](evidence/R8/reference/03-deckcraft-insert.jpg)
4. 旧 JoyDeck 实测：多排路径/验证按钮、常开工程属性侧栏、画布空间被挤占，操作不符合参照。属于需要重做的主编辑流程。[截图](evidence/R8/reference/04-joydeck-before.jpg)

5. 同一 PPTX 的主界面对照：[DeckCraft](evidence/R8/reference/05-deckcraft-same-pptx.jpg)、[最终 JoyDeck](evidence/R8/gui/25-final-editor.jpg)。布局已接近，完整功能与控件状态尚有下表差项。

## R9-UI1 后续切片

2026-11-03：在 JoyOffice 内现场复查 DeckCraft 0.14.1 与本机 PowerPoint 中文界面。字体改为 GPUI Kit 可搜索已安装字体列表；字号使用独立常用值/自定义选择、增大/减小及 Ctrl+Shift+./,；颜色使用主题/标准色块、当前颜色指示和自定义六位 RGB。主题色存为 scheme 引用，保留跟随主题的能力。每项仍进入原有 text transaction；完整字体环境/混合格式指示/所有字符格式、最近文件/模板、审阅和其他差项继续保留。最终包已实测 Windows 标点归一化修复后的字号快捷键、Undo/Redo、PPTX 原生另存/独立读回/重启重开；证据为 gui/12–23。详见 [本轮证据](evidence/R9-UI1/README.md)。

## R9-UI2 格式与工作区增量

2026-11-09：现场对照 DeckCraft 0.15.8 和 PowerPoint 的页脚入口。JoyDeck 分开呈现当前缺失页、全部缺失页和更新已有页脚，以便在混合内容中明确应用范围。Windows 实屏与 PPTX 核对通过。全稿清空入口单独确认，保留页脚占位框，并可单步撤销。[续验](../joyoffice/validation/20261109-p1-followup/README.md) · [JD-305 验收](../joyoffice/validation/20261109-v012/README.md#p1)

2026-11-03：新增继承后混合格式、显式 caret 格式与逐 run 字号步进；段落行距／缩进／段距对话框和列表选择；表格区域、样式、底色、边框、边距、方向、尺寸和结构控件；整体变换、页面排序／隐藏／节、最近文件／原创模板、多窗口和基础审阅／比较。没有把完整 Ribbon、制表位、母版、复杂脚本、所有手柄或全部旧命令标为完成。最终自动检查已通过；解锁后的格式／表格／审阅等 GUI 已独立读回；模板／UIA 关闭竞态／主题同步已修复，最终包格式保存、审阅和最近文件重开、跨窗口主题与独立关闭补验通过；窄窗口和全 DPI 仍未完成本轮验证。新旧证据与保存限制见 [R9-UI2](evidence/R9-UI2/README.md)。下表是 R8／UI1 对照基线，新变化以上述记录为准。

2026-11-05：在「形状格式」接通文字框方向、分栏、垂直对齐、边距、换行与溢出缩小。实屏验证中文竖排、从右向左分栏和混合边距，另存与独立读回复验保留原段落和链接。随文字调整形状和其余文字命令继续由 JD-305 跟踪。[文字布局](evidence/R3-TEXT-LAYOUT/README.md)

2026-11-05：在「插入」新增文字链接和移除入口，支持网页、邮件、页码与屏幕提示。链接范围支持混合字符格式，光标在已有链接内时可编辑其完整范围。另存及重开后的放映跳转已从 macOS Release 验证。[文字链接](evidence/R3-TEXT-LINKS/README.md)

2026-11-05 在「插入」接通文本框内的动态幻灯片编号和 13 种日期／时间格式。实屏验证短日期选择、字段整体删除与撤销、原始 XML 保留，以及重排后页码更新。固定日期、整份文稿的页脚与应用到全部页面继续开放。[动态字段](evidence/R3-TEXT-FIELDS/README.md)


## 2026-11-10 macOS PowerPoint Ribbon 对照

参照本机简体中文 Microsoft PowerPoint 16.114.4 的展开式 Ribbon。常驻页使用空白文稿，上下文页使用选中的标题占位符及同一份图片、表格、图表样例。PowerPoint 窗口截图为 1600 × 900，JoyDeck 开发构建为 1440 × 900。原始截图供本机验收，产品继续使用 JoyOffice 共享图标。

macOS 把快捷工具放入原生标题栏，文件入口保留在快捷工具和系统菜单中。Ribbon 改用平面底色、选中下划线、紧凑双行控件和无可见组标题的分隔线。辅助功能树保留分组名称及选中状态。内容超出窄窗口时可横向滚动。

| 现场参照 | JoyDeck 调整 | 主要差距 |
| --- | --- | --- |
| 开始 | 剪贴板、幻灯片、字体、段落、插入对象、排列依次布局。新建幻灯片提供分裂按钮，复制和删除收进下拉菜单 | 格式刷、重置和部分文字工具显示禁用 |
| 插入 | 重排表格、图像、插图、链接、批注、文本、符号与媒体。复用页脚、日期、页码和链接编辑命令 | 屏幕截图、SmartArt、图表新建、公式和媒体插入等仍禁用 |
| 绘图 | 绘图工具和笔图库 | 暂无文稿墨迹编辑，控件禁用 |
| 设计 | 显示当前主题和内置主题预览，重排颜色、字体、背景、版式和幻灯片大小 | 主题预览只读，完整主题应用和设计建议仍待实现 |
| 切换 | 显示效果图库、当前效果、持续时间、声音和换片状态 | 控件只读，暂不支持在此编辑或应用全部 |
| 动画 | 区分进入、强调、退出、路径和计时 | 控件禁用，动画编辑和窗格仍待实现 |
| 幻灯片放映 | 对齐从头播放、从当前页播放及演示者视图，接入已有隐藏幻灯片命令 | 设置、排练和录制仍禁用，设置项只读 |
| 录制 | 对齐摄像头、开始录制和清除录制分组 | 控件禁用，暂不支持录制 |
| 审阅 | 对齐校对、辅助功能、语言、比较及批注分组 | 保留 JoyDeck 文稿工具，拼写、翻译和完整检查仍待实现 |
| 视图 | 区分文稿视图、母版、显示、缩放和窗口工具，增加可输入百分比的缩放入口 | 大纲、阅读、母版和标尺等仍禁用 |
| 形状格式 | 增加插入形状、替代文本、排列和大小组，保留文字布局 | 快速样式和完整图库仍待实现 |
| 图片格式 | 按调整、样式、替代文本、排列、裁剪和大小分组 | 图片样式、去背和完整图片调整仍待实现 |
| 表格设计 | 展示样式选项状态及可应用的内置样式预览，集中底纹和边框 | 完整样式选项和画表格仍待实现 |
| 表格布局 | 集中选择、行列、合并、对齐和尺寸命令 | 部分操作仍在菜单和对话框中 |
| 图表设计 | 重排图表标题、类型图库和数据编辑 | 图表样式、快速布局和完整 Excel 数据编辑仍待实现 |
| 图表「格式」 | 单列选中图表的排列和大小入口 | 图表元素级别的填充、样式与属性仍待实现 |

最终 macOS ARM64 开发构建已逐页实屏复拍 10 个常驻选项卡，并验证新建幻灯片的下拉菜单可复制幻灯片，撤销恢复为一页。选中标题占位符后，辅助功能树可见「形状格式」。桌面锁定前未完成新版六个上下文页、窄窗口和深色模式的实屏复验。PowerPoint 的对应上下文页已全部截图。自动检查含严格 Clippy 和 974 项测试，全部通过。

本轮继续推进 JD-508 和 JD-804。功能覆盖沿用命令矩阵，暂不可用控件不计入已实现命令。该对照范围仅为当前 macOS 配置下的展开式 Ribbon。
