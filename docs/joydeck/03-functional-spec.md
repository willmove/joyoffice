# 功能规格与验收契约

版本：2.0，2026-10-29。M0 Windows 与 M1 只读浏览子集已实现；完整状态见14、17、19、22，其余要求待实施。阶段列表示首次必须验收的阶段；后续仍需回归。P0/P1/P2 是本产品优先级，以用户可观察结果验收。本文与 [领域技术规格](04-architecture-spec.md) 共同约束实现。

## 1 应用与工作区

| ID | 优先级 / 阶段 | 要求及验收条件 |
|---|---|---|
| FR-APP-01 | P0 / M0 | GPUI 原生窗口启动、缩放、最小化、关闭正常；可看到版本、构建和图形诊断；初始化失败有可理解的错误出口 |
| FR-APP-02 | P0 / M1 | 工作区含工具区、缩略图、画布、属性区域、备注和状态栏；当前页和缩放变化同步；空、加载、失败、只读状态均可辨认 |
| FR-APP-03 | P0 / M2 | 常用命令可从工具栏、菜单、快捷键和命令面板触发；enabled/disabled reason 一致，禁止显示能点击但无效果的占位入口 |
| FR-APP-04 | P1 / M6 | 多文档与多个编辑窗口由同一 DocumentId 管理；同文档多窗口编辑同步，历史不分叉；关闭窗口与关闭文档行为清楚 |
| FR-APP-05 | P1 / M0→M6 | M0 证明明暗主题和简中/英文切换；M6 全部已实现界面使用资源 key，缺失翻译回退英文；不翻译用户文稿或命令 ID |
| FR-APP-06 | P0 / M3 | 文本框、画布、属性和弹窗之间焦点可预测；焦点不在画布时，Delete/Ctrl+A 等不会误操作幻灯片对象 |
| FR-APP-07 | P1 / M6 | 工具栏、缩略图和属性控件具备可见键盘焦点、role/name/state；画布对象有可访问语义，最终三平台读屏验收在 M13 |
| FR-APP-08 | P1 / M13 | 最近文件、偏好设置、窗口布局可持久化；坏配置可重置，缺失路径可移除；不持久化失效的窗口句柄和指针 |

## 13 统一异常语义

无文档、空页面、无选择、混合值、对象删除、文件损坏、缺字体、图形设备丢失及媒体不支持都有明确状态。错误应含稳定 code、用户可读 message、可选页/对象/路径定位及恢复动作；同一错误在 UI 与自动化仅表现形式不同。

取消通常是成功的用户决定，不显示成系统故障。不可恢复的文件错误不阻止用户继续编辑其他文档。长任务完成后若对应文档/窗口已关闭，结果应回收或进入任务中心，不写入新的活动文档。
