# JoyDeck 实施状态

2026-11-02：JoyDeck 0.4.0 / R3 文字输入与表格基础切片。Rust 1.98.1、GPUI Kit 0.8.1 / pre 0.3.10，与 JoyOffice 保持一致。应用、CLI 和 crate 均使用 joydeck 命名。

## 本轮实现

- 基于同一 DeckCraft TextBody/edit 与 CPU 布局的原位文字输入，光标/选区/命中/候选锚点一致。双击或工具栏进入，支持普通水平未旋转的顶层文字和表格单元格。
- 复用 JoyOffice UTF-16/grapheme、组合草稿与 EntityInputHandler 适配。候选提交进入统一引擎，预编辑不进入历史/保存/恢复；取消组合保留已提交模型。范围编辑保留其他 run 和段落，支持选区粗体/斜体。
- 表格插入、单元格编辑、Tab/Shift+Tab 导航、行列增删、合并/拆分与底色；有界 TSV 区域粘贴是一个事务。越界、覆盖格和预算失败不部分修改。
- 系统 Unicode 与内部带版本富文字片段剪贴板；整表 TSV 复制、区域粘贴。备注复用 JoyOffice Textarea，以“应用备注”提交。
- PPTX writer 增加表格和已有演讲备注保留写回，保存前检查表格单元格/合并/底色和备注。未知/扩展行列结构和编辑后的超链接关系等拒绝公共写回，可保留为 .joydeck v2。
- Windows MSVC 桌面栈预留 8 MiB，解决 debug 组合视图树超过默认 1 MiB 的启动问题；未修改系统设置。

## 验证与交付

实际结果与开发包见 [R3 验证记录](evidence/R3/README.md)。独立 python-pptx 读取实际写出的 PPTX；检查原始文件不变、未触及成员字节、未知单元格属性保留和受限结构拒绝。R0/R1/R2 包保留。没有修改源 JoyOffice/DeckCraft 目录。

## 后续与限制

本轮为基础切片，不宣称 R3 所有完成条件已验收。字体环境变化/variation 身份与缓存失效、旋转竖排和完整文字滚动、全部字符/段落/列表/超链接 UI、矩形表格选区、图片/跨文稿对象及 HTML/RTF 剪贴板、复杂 IME/焦点竞争、多窗口仍需后续。动态字段、公式和不支持的文本形态明确拒绝原位输入，原始数据保留。

CPU 文字布局同时服务画布和命中，未引入另一套 GPUI 排版。画布仍是共享 CPU 参考渲染器；GPUI 原生对象/定位字形和性能验收属于 R4。每次最新文字更新期间可保留同页旧预览，后台完成后替换，不承诺 R4 延迟目标。

撤销历史仅本次会话，恢复重新建立历史；未提交组合/备注表单草稿不在恢复中。PPTX 未承诺 PowerPoint 全保真，修改 XML 可重新序列化。缺少可复用演讲备注部件时请另存项目。Windows x86_64/MSVC 为本轮实际环境，macOS/Linux 未原生验证。开发包未签名；正式安装/更新、完整许可文本分发审计仍属后续。
