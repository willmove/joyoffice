# JoyDeck 实施状态

2026-11-03：JoyDeck 0.7.0 / R6–R7 文件输出、放映与控制纵向切片。Rust 1.98.1、GPUI Kit 0.8.1/pre 0.3.10 与 JoyOffice 一致；PDF 采用同源官方 Krilla 0.8.2。产品/模块仍名 joydeck。

## 本轮行为

- 复用固定 JoyOffice 的私有只读旧 DTO/格式，验证 1.0–1.11 基础迁移，通过公开 OOXML 接入新模型；新项目附带精确原件、转换警告和 ID。旧媒体/审阅/放映链接、未来/未知必需特性明确拒绝，完整旧功能迁移仍在推进。
- 显式 PPTX 保留写回与重新生成副本；后者可生成 PPTX/POTX/PPSX 并报告损失。签名/宏启用源拒绝普通保留写回，原生项目可保留原件。
- PDF 图形与准确可检索字形子集、Unicode、链接、书签、备注/讲义；PNG/JPEG/GIF、提纲/RTF、静态 MP4/标题 VTT；Windows 系统打印对话框和取消。
- 独立观众与演示者窗口、隐藏/自定义/范围/循环顺序、已有动画与转场状态、临时墨迹/激光、暂停/黑白、Windows 本地内嵌单片段解码/播放/seek/静音。放映采用共享 CPU 时刻状态；不另行塑形文字。
- 版本化无界面 control 和 MCP 2025-11-25 stdio，文稿 ID/选择修订/重放/路径根限制，有界异步导出任务和取消。控制不附着正在运行的编辑器，无 TCP 监听。

## 验证与交付

本轮完整检查通过 860 项 Rust、5 项 Python；fmt、严格 Clippy、CLI/核心隔离、261 项引入来源指纹和文档门禁通过。独立 pypdf/Poppler/Windows 解码验证已执行，最终 Windows 包与桌面证据见 [R6/R7 验证记录](evidence/R6-R7/README.md)。R2–R5 的编辑、输入、保存/重开、恢复与场景基础能力继续保留。源 JoyOffice 与 DeckCraft 未修改，旧开发包保留。

## 仍需推进

完整 R4–R7 和 329 命令覆盖保持进行中。旧媒体/审阅原生迁移、完整 OOXML 保真/共享 DrawingML 收口、全部动画编辑/反向转场、排练持久化、真实多屏/DPI/睡眠/音频设备与完整音画同步、多片段、跨页/旋转媒体、附着桌面的控制、PDF/A/标记 PDF、实体打印和 macOS/Linux 原生资格化仍待完成。

MP4 仅静态页，不包含动画/媒体/音频/备注；VTT 仅标题。字体按本机环境嵌入允许的子集，不分发系统字体。Windows helper 为自有源编译、依赖系统组件；本包未签名，许可全文缺项和正式发行资格另行审计。基础切片不代表整阶段已验收。
