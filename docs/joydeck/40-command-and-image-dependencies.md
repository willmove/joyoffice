## M12已注册领域命令

`command.execute`此前只开放page.add、object.add、review.edit。现在覆盖全部16个已注册领域命令：页面增删复制/重排/隐藏/尺寸，对象增删/批量属性/图层，表格，设计，持久化动画，媒体参数和审阅，以及复合事务。参数由引擎强类型解码，完整接口、表格/设计子动作及示例见[命令目录](16-command-inventory.md)。

增加`command.validate`和可选`expectedRevision`。校验和提交共用草稿准备、依赖清理、模型验证与8MiB模型预算；校验不发布文稿、历史或ID游标。未知参数、无效或重复选择、陈旧修订和嵌套/数量超限拒绝。批量删除按原索引逆序执行，复合命令失败整次回滚；一次执行只进入一条undo。

编辑中的新对象ID使用会话命名空间和事务内游标。不同会话的新对象不共用ID；校验不消耗正式编辑的游标，失败也不发布游标。已有原生文件的ID保持原值，保存schema不变。UI、CLI和MCP仍使用同一个编辑内核；不同新会话的分配ID允许不同，语义和引用关系须一致。

`engine.commands`从注册目录生成ID列表，并提供固定的参数名、索引单位、schema版本和预算。新增本地/远程MCP全目录验证脚本`verify-command-catalog.py`，逐命令检查校验不变、实际提交、operationId重放、单次undo/redo及两种后端语义一致。已有显式operationId和目标/roots/请求预算契约不变。

## M14图片依赖迁移

比较接受增加显式`includeResources: true`；GUI增加“接受并复制所需图片”。只复制所选新增/替换图片对象引用且目标尚缺的内容寻址PNG，保留稳定对象ID和参考图层。原有未选择此选项的缺资源拒绝行为保持不变。

图片资源与对象采用同一事务，统一检查hash、解码/尺寸、单资源与总量、模型预算；任一失败不发布资源、对象、历史或修订。一次undo移除本次带入的资源，redo和原生保存重开保持相同语义。比较面板重启比较时清除旧报告并按请求代次丢弃迟到结果，防止显示另一份参考文件的报告。

这只完成图片资源迁移子项；版式/母版/主题、媒体/动画/审阅依赖和三方冲突选择未在本次自动迁移。页面/主题等差异仍报告，不能把图片接受称为完整合并。
