# M9 图表与基础图示实现报告

日期：2026-10-30。M9本机受支持范围完成；102项测试、最终构建、原始日志、像素误差和包哈希以 [M10最终验证索引](evidence/m10/final-verification.json) 为准。本次与M10合并交付，不代表完整Excel、Office SmartArt或任意PPTX无损编辑。前序完整里程碑的开放项继续保留。

## 实现

新增独立Chart/Series模型：柱形、条形、折线、面积、饼、环形、散点；分类、系列、有限数值和空值；标题、图例、网格、标签、轴标题/单位/范围及调色板。散点X/Y空值不填零，跨系列共用X范围，全空数据仍生成有限坐标轴。饼/环形图限一个非负且总和大于零的系列；环形内径固定50%，不同内径导入给出诊断保留源包。面积图为非堆积，空值分段封闭至零基线，不跨缺值连接。图表在CPU、GPUI Scene、缩略图、图片/PDF输出和放映中使用同一数据。普通图表走路径/字形；需要裁剪或不支持子树时有局部栅格回退。

图表页签有真实数据网格与TSV草稿，两者分别应用；不是把UI表格序列化成文档表格。数据/类型/样式改变通过ReplaceObject单事务提交，非法数值、形状、预算和不合法类型切换整次拒绝，undo/redo恢复模型。选中不同对象和撤销后同步草稿；跨文稿复制基础图表/图示和原生重开通过。

新增基础图示模型：列表/流程/层级、文本面板、布局切换、连接线和颜色；文本面板Tab缩进最多8层、每图最多64节点。导入SmartArt的受支持dataModel文本/父子拓扑会明确标为简化转换；原始布局、样式、绘制缓存保留在源包。新建PPTX输出普通形状组，不声称写出了完整SmartArt。转换为独立形状前提示层级、自动布局、对象动画目标的损失，一次撤销可恢复。

## 格式与边界

公开输出为真实DrawingML chart、关系和嵌入XLSX。公式、数值缓存、空单元格和工作簿由同一模型生成，输入修改后一起更新。基础公共读取支持缓存、常见直接颜色、轴范围/标题等；数值单列引用会与嵌入工作簿核对。冲突不以旧缓存冒充最新数据，而是给出诊断和占位，保留完整源包。组合、堆积、3D、chartex、趋势线、误差线及复杂公式不在本轮编辑范围。

每图1–256类别、1–16系列、最多4096点；文稿16384点；数值绝对值≤1e12；TSV≤128KiB。标签、系列名、颜色、轴范围、矩形和饼图数据有独立校验。嵌入工作簿≤4MiB压缩、8MiB展开、128部件；同时受外层ZIP/XML预算约束。没有计算Excel公式、宏或外部链接。绘制还有单对象50000/单页100000字符的布局预算，预算失败保留内容并提示。

原生writer为schema1.8/minReader9，charts-v1涵盖基础图表/图示，motion-v1涵盖时间线/放映参数；兼容读1.0–1.7。未知必要特性/更新reader要求仍拒绝，旧文件和旧版回退包保留。源包模式保持原有闭包字节，仅支持唯一单run/单段/单行文字补丁；图表/图示/时间线变更不能伪装成源包无损写回，新建导出有损失确认。
