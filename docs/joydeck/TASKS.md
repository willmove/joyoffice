# JoyDeck 重构任务清单

日期：2026-11-02。方案见 [PLAN](PLAN.md)，依赖规则见 [DEPENDENCIES](DEPENDENCIES.md)。R0 Windows 开发切片及检查点已实现；逐项证据、适用范围和未验证平台见 [STATUS](STATUS.md) 与 [R0 记录](evidence/R0/README.md)。

任务编号使用 `JD-xxx`，避免与现有 JoyDeck 的 `T-M*` 历史任务混淆。状态依次使用“待开始 / 进行中 / 已实现待验收 / 完成 / 阻塞”。每条完成记录必须链接当次源码、检查和适用的桌面证据。

每阶段最后一项为可运行交付：构建当前阶段源码、启动当次产物、执行桌面场景、检查截图、打包并保存校验和。阶段中的任务可以小步提交，但阶段完成时必须能独立体验。

## 命令和界面的覆盖规则

[COMMANDS.csv](COMMANDS.csv) 为 329 条静态命令登记初表，包含上游源码位置和建议阶段。建议阶段只是路由提示：同一命令可能跨阶段分次接入，最终以真实语义验收为准。

逐条填写 UI 入口、支持范围、引擎/CLI 回归、桌面证据和状态。查询命令可以只保留无界面入口，但必须说明；需要用户交互的命令不能靠 CLI 已存在来计作 GPUI 完成。UI 对话框和旧 JoyDeck 独有功能另由 JD-508、JD-506、JD-706 登记，不能用命令条数代替完整功能矩阵。
