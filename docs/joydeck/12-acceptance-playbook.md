# 分阶段验收与演示手册

以下为完整验收契约；Windows M0 与 M1 基础浏览子集的实际结果见 [17](17-m0-implementation-report.md)、[19](19-m1-implementation-report.md)。未测条件仍为待验收。测试使用授权的临时文稿和输出目录；异常退出、损坏文件及设备断连不针对用户正式工作文件。

## 1 执行约定

先记录阶段/commit、OS/CPU/GPU/驱动/DPI、toolchain、lock、features、字体及数据版本。构建用 `cargo build --locked -p joydeck`，交互用 `cargo run --locked -p joydeck`；性能另用 release。当前工程已提供这些入口。

每个 AT 记录通过/失败/未执行/不适用、实际步骤、观察、日志/必要截图、产物位置和复现 seed。没有实际测试的 OS 不写通过。阶段手工演示通常 3–10 分钟；长跑、语料和性能检查独立记录，不通过缩短演示掩盖。

## AT-01 启动与技术诊断

阶段：M0。前置：已建立最小工程与可运行包。

1. 从终端和分发目录各启动一次，检查窗口、版本、后端和错误日志位置。
2. 点击按钮/菜单，打开并关闭 modal，Tab/Shift+Tab 浏览焦点。
3. 切换明暗和简中/英文；输入中文预编辑、提交和取消。
4. 显示 path 与透明图像，改变窗口/DPI；开关第二个窗口。
5. 启动耗时诊断任务并取消，关闭任务所属窗口，确认结果不会串入另一个窗口。

通过：真实 GPUI 控件和绘制可见；文字不缺失；任务不冻结窗口。保存依赖/API/平台结果和截图。此项不证明真实幻灯片富文本输入已实现。

## AT-02 文件浏览与渐进加载

阶段：M1。前置：SMALL、LARGE、native/PPTX 与受控损坏样本。

1. 打开 `.joydeck` v1 和受支持 PPTX，各观察当前页/页数/告警。
2. 快速翻页和缩放，观察最后选择页是否被旧任务画面覆盖。
3. 滚动长缩略图列表，观察占位渐进显示和内存。
4. 打开 LARGE 后取消；原活动文稿仍可操作。
5. 打开损坏或不支持内容，检查只读/缺字体/兼容报告及定位。

通过：没有“加载中变成另一个文档”或无提示白页；只读阶段不能编辑/保存。记录首屏、总读取、cache/raster 和 RSS。

## AT-03 基础编辑与历史

阶段：M2，后续回归。

1. 新建三页和矩形/椭圆/箭头，框选、多选、移动/缩放/旋转。
2. 拖动中按 Esc，确认位置、尺寸和选择回到原状态。
3. 修改颜色和数值，撤销/重做到起点；一次拖动只退一步。
4. 复制/隐藏/重排页面，多选删除再撤销，页 ID 与对象引用正确。
5. 输非法数值和无效命令参数，确认文档保持有效且错误可解释。
6. 保存 native，关闭再打开，对比文档语义与画面。

通过：模型/视图/历史一致，无半次操作、重复 ID 或空页异常。应自动覆盖事务/取消/历史不变量，手工演示关注实际交互。

## AT-04 画布文字与 IME

阶段：M3；M8 增表格，M13 全平台。

1. 在真实画布文本框内输入中英、日/韩文、emoji、ZWJ emoji、组合音标和换行。
2. 中文预编辑移动候选、提交；再组合后 Esc 取消；检查候选窗口在光标旁。
3. 用方向键、Home/End、Shift、双击词、三击段、Backspace/Delete 操作范围。
4. 局部加粗/改色、插入列表、跨段选择；多次撤销至输入前，再重做。
5. 组合中切页/进属性/保存/关闭，验证约定的 settle/cancel 和焦点 ownership。
6. 125%/200% DPI、缩放及旋转文本内重复；M8 在表格单元格重复。

通过：不重复提交、无半个 Unicode 字符；一次组合提交一次撤销，光标/选区/预编辑和 glyph 一致；保存重开不含未提交临时文字。不同 OS 的真实输入法均记录。

## AT-05 焦点键盘与应用无障碍

阶段：M3 基础，M6 扩展，M13 最终。

1. 选中画布对象后在字号/搜索框输入，按 Ctrl/Cmd+A、Delete 和撤销。
2. 弹出 modal，Tab 焦点不能落入后面的画布；关闭后回到原有效元素。
3. 用键盘走完新建、选择、文字编辑、改格式、保存、进入/退出放映。
4. 切工具区、缩略图、画布、属性和备注；验证可见焦点和可离开画布的路径。
5. 用 NVDA/VoiceOver/Orca 检查按钮、混合值、选择、对象名称和错误提示。

通过：输入不穿透、不误删对象；可访问 role/name/state/action 与视觉相符。不能只根据 AccessKit 节点存在判读屏通过。

## AT-06 保存关闭与恢复

阶段：M2，M7/M13 扩展。

1. 对 dirty 文档分别执行关闭页签、关闭文档、窗口退出和应用退出。
2. 每个入口分别选取消、保存、放弃；取消保持状态，保存失败不关闭。
3. 对只读路径/空间不足/目标被占用等测试注入错误，验证旧目标文件仍完整。
4. 编辑后等待一次恢复写入，在临时测试实例强制异常结束；重启选择恢复。
5. 验证源文件不被覆盖；在恢复列表中区分损坏、另一个实例占用和不支持版本。
6. 恢复后继续编辑、保存另一路径；检查恢复清理与配额。

通过：所有路径无静默丢数据；清 dirty 只对应实际成功写入的 revision。记录 target hash、恢复 revision 与失败时文件完整性。

## AT-07 画布加速与画质

阶段：M4，所有新增对象继续回归。

1. release 下加载固定 BENCH-EDIT，在 CPU baseline 与新后端执行相同拖动/缩放轨迹。
2. 收集 input/commit/layout/raster/upload/paint/present、缓存字节、p95/p99 和后端覆盖。
3. 只移动光标、hover、框选；整页 raster/upload 计数不应增长。
4. 对文本、裁剪图片、透明组和阴影比较 CPU/GPU；检查换行、z-order、alpha 及 extent。
5. 快速缩放、切页、改变字体/母版，再结束交互等待高质量补图。
6. 注入可控 GPU cache 重置/设备故障路径，确认文档和恢复能力保持。

通过：满足 06 的 M4 覆盖与相对/阶段门槛；Beta 再满足 09 绝对门槛。只显示旧 RGBA 不能算通过。保留同机原始数据和可视对照。

## AT-08 图片剪贴板与复杂对象

阶段：M5。

1. 文件/拖放/系统剪贴板各插入一张图，检查方向、alpha、fallback 和像素预算。
2. 裁剪、改纵横比、重置；取消预览不改变原图引用。
3. 插入两个形状并连接，移动/旋转/组后仍正确连接；删目标再撤销。
4. 嵌套组内选对象，对齐/分布/锁定/隐藏，检查选择面板和命中。
5. 插入受支持 SVG/EMF/WMF 和恶意外部引用 SVG，确认不联网/执行。
6. copy/delete/undo、关闭源文档、保存重开，图片/连接/组均保留。

通过：三平台图片粘贴单独验证；资源不会因关闭源文档丢失。记录不支持 metafile/SVG 特性的可解释行为。

## AT-09 母版主题与跨文档

阶段：M6。

1. 建立两个母版、多个版式和匹配占位符，制作引用页。
2. 改母版标题字体/主题色，检查继承页同步、直接格式保持。
3. 应用/重置版式，文本内容不丢失；删除在用版式需替代或拒绝。
4. 编辑页码/页脚、备注、节、大纲，切换视图保持有效选择。
5. 跨文档复制页，分别选择保留源格式/使用目标主题，检查资源/ID/母版重映射。
6. 双窗口对同文档分别选择对象，再修改/撤销；两窗口内容同步但选择不相互覆盖。

通过：无悬空引用、主题正确失效，native/PPTX 往返再检。保存多母版样本的规范化模型与必要画面对照。

## AT-10 PPTX 兼容与往返

阶段：M7，M8–M13 扩充。

1. 读取指定语料的授权/版本/字体说明，打开并查看 CompatibilityReport。
2. 无编辑另存，检查部件图、文本/对象/媒体和未知 payload hash。
3. 重开、修改指定已支持对象，再存再开，对比继承、文字、图形及未编辑对象。
4. 对 SmartArt/OLE/嵌入图表/未知扩展检查完整 relationship closure。
5. 用已记录版本的 PowerPoint 打开输出，确认无修复提示；按条件对照画面。
6. 对已知有损对象执行覆盖保存，确认先看到损失清单并默认另存；取消不写文件。

通过：所有声明 C2 的样本无静默内容损失、无悬空关系、无修复提示；视觉差异区分抗锯齿与布局错误。真实语料缺失时维持较低声明，不把“合成文件通过”写成完全兼容。

## AT-11 输出与打印

阶段：M7 基础，M12 扩展。

1. 对当前页/范围/隐藏页导出 PNG/JPEG，检查尺寸、alpha、DPI 和命名。
2. 导出 PDF 幻灯片、备注、讲义，检查页码/纸张/方向/边距及不含编辑控件。
3. 选择/提取 PDF 文字，检查无双重文本、链接和书签；放大检查声明的矢量覆盖。
4. M12 对同页 CPU/GPUI/PDF 做几何/文字语义和视觉对照，复杂 filter fallback 如实标记。
5. 用 OS 打印对话框选择页范围、打印到测试设备/PDF；取消不改文档。
6. 大纲/RTF/GIF 输出核对内容、静态/动画范围与时长；未实现 MP4 不出现可执行入口。

通过：输出可打开、可定位，实际质量与界面说明相同。可选择文字不被当作 Tagged PDF 的证明。

## AT-12 放映动画与双屏

阶段：M7 静态；M10 完整。

1. 从首张/当前页放映，检查隐藏页、自定义顺序、键盘/点击和退出。
2. 配置点击/与前/之后、按段构建、repeat/rewind，比较编辑预览和放映采样。
3. 对基础转场/Morph 匹配、重复名称、缺对象和不支持效果检查 fallback。
4. 选择观众屏，演讲者屏显示备注与下一页；交换屏幕，改变 DPI。
5. 黑屏/笔/跳转/返回、暂停/恢复、排练；结束选择保留或丢弃笔迹。
6. 拔插外屏、切镜像、睡眠唤醒；检查备注不会误投、不会连续跳页。

通过：两个窗口单一时钟，观众无私密 UI；BENCH-SHOW 帧时达标，native/PPTX timing 与媒体参数保留。需真实双屏证据，模拟窗口不能代替。

## AT-13 媒体

阶段：M11。

1. 插入经验证 WAV/MP3/H.264 MP4；插入不支持 profile、坏流和缺资源样本。
2. 播放/暂停/seek/trim/volume/loop，各反复 20 次，检查旧帧/旧 PCM 不回流。
3. 测跨页音频、autoplay、rewind 和返回页的既定策略。
4. 连续播放 10 分钟测 A/V drift/丢帧/队列/RSS；后台 UI 继续可操作。
5. 切换/拔掉音频设备，确认静音/失败提示不阻止结束放映。
6. 保存重开与 PPTX 往返核对 trim/loop/volume 等模型参数。

通过：满足指定格式/profile/硬件预算；不支持流明确失败，不能以海报替代却显示正在播放。

## AT-14 并发版本与多实例

阶段：M2 初版，M6/M7/M12 完善。

1. 开始保存 revision R，保存未结束继续编辑成 R+1；R 成功后仍显示 dirty。
2. 对同一路径连续发起保存，模拟前次较慢；最终文件必须是正确顺序的最新成功快照。
3. 快速切页/改字体，让旧渲染/打开任务晚到；不得串写新文档。
4. 两窗口/实例打开同文件，外部修改后保存，检查 conflict/另存/重载。
5. 后台任务中关闭文档窗口或全部应用，检查取消/回收/任务结果策略。
6. M12 同 request ID 重发修改命令和超时重试，确认去重及 outcome-unknown 语义。

通过：revision、文件状态和 UI 标签一致，没有旧快照覆盖新内容。自动测试通过可控调度制造顺序，避免靠固定 sleep 的偶然成功。

## AT-15 超限与性能

阶段：M1 起，M4/M13 完整。

1. 加载超大声明图像、深组/XML、过多 ZIP 项、重复/逃逸路径、非有限坐标和坏媒体。
2. 验证分配前预算、累计 inflate work、取消及错误定位，原文档不变。
3. SMALL/LARGE/EFFECT 按固定协议测 cold/warm、CPU/RSS/GPU/cache/queue。
4. 连续打开关闭 20 轮，检查派生资源与私有内存回落。
5. 资源压力下编辑/撤销/保存，确认先回收缓存而不是丢用户历史或文件资源。

通过：预算有界，目标性能有原始数据，超限可解释；测试不允许因防护把合法数据悄悄截断后覆盖保存。

## AT-16 表格

阶段：M8。

2. 合并标题、拆分、插删行列、改变宽高及均分，检查 range/主单元格。
3. 应用主题样式和边框，再做局部覆盖，切主题后验证继承。
4. 粘贴 TSV；超限/非法矩形粘贴失败应回到原表。
5. 撤销/重做全部操作，保存 native/PPTX 并重开。

通过：结构/文字/边框/合并一致，无半提交和非法 cell span；生产画布有真实表格编辑，不只是数据面板。

## AT-18 CLI 控制与 MCP

阶段：M12b。

1. 无显示器运行 CLI inspect/run/render/convert，用 UI 构造相同文稿，对比规范化模型。
2. 未开启控制时检查无监听；开启后未认证/错误 token 请求均拒绝。
3. 分别测试 read root/write root、路径逃逸、超限 JSON、队列满和客户端中断。
4. 同请求重发、新旧 target、queued cancel/running timeout/结果未知，检查不重复修改。
5. headless 与 remote MCP 按所选版本完成能力协商、工具查询/调用、通知/取消及错误响应；新版 discover/请求级元数据与旧版 initialize 分开测试。
6. dirty close 无策略返回明确错误，带 save/discard/cancel 策略才执行；stdout 没有日志污染。

通过：自动化和 UI 语义一致、可控失败，不依赖隐形 modal，协议与依赖版本有记录。

## AT-19 审阅与文稿无障碍
