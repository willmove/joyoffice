## 试用

解压 Windows M7-alpha 包，双击 `Open advanced workflow.cmd` 打开随包样例。也可运行：

```powershell
.\joysheet.exe docs/samples/M7-workflow.xlsx
.\joysheet.exe --sample sales --control 7979
.\joysheet-cli.exe mcp --connect 7979
```

1. 在“分析与透视”中创建透视表，选择来源和输出位置；在字段面板用按钮或拖放调整行、列、值和筛选字段。分析工具提供 13 类参数入口，单变量求解与规划求解共用引擎。
2. 在“审阅”中添加批注/回复/笔记，定位、解决或删除；保护表格和工作簿；名称管理支持新增、改名、删除及引用更新。
3. 在“动作与脚本”中开始录制，操作后停止并命名；编辑器使用命令数组 JSON。重新打开工作簿默认不信任，运行前显示命令预览并要求明确确认。任务列表显示已完成步骤，可在命令之间取消。
4. 在“桌面控制”查看实际端口、复制 MCP 配置及选择窗口。`--control` 未指定时不会启动服务。指定 `window` 或 `doc` 的保存会先提交该窗口草稿，并返回完成后的版本。

开发启动：`pwsh -File scripts/dev.ps1 run --locked -p joysheet -- --sample sales`。

构建：`pwsh -File scripts/dev.ps1 build --release --locked -p joysheet -p joysheet-cli --features joysheet/automation`。

回归：`pwsh -File scripts/dev.ps1 xtask ci` 和 `pwsh -File scripts/dev.ps1 xtask smoke --stage M7`。指定解压包回归：

```powershell
pwsh -File scripts/desktop-smoke.ps1 -BinaryDirectory artifacts/M7-package-smoke/joysheet-0.1.0-M7-alpha-windows-x86_64 -M4Task 4 -M5Task 4 -M6Task 4 -M7Task 4
```

## 范围与边界

- 保留原引擎的透视、分析、求解和场景语义；复杂约束、计算字段及部分高级选项仍可用高级 JSON 参数。已验证常用样例，不代表每种分析模型均已单独原生验收。
- 脚本是原有命令序列；包含 VBA 的文件仅保留项目，不执行 VBA。信任覆盖本次会话中该工作簿的脚本，重新打开即撤销；沙箱预检拒绝文件等非脚本能力。
- 取消在命令之间生效，不能打断一个正在计算的公式或求解；已完成普通命令保留、可撤销，未闭合的撤销分组回滚。进度显示已完成步骤，未作后台增量工作簿发布。录制沿用上游会话日志语义，建议录制期间只操作当前文档，跨文档录制仍列为限制。
- CLI/MCP 低层 `engine.execute` 与桌面 `ui.command` 的草稿语义有区别；保存/打开/新建已统一，其他命令仍按协议说明使用。完整兼容对照及明确不支持项见 [控制接口](CONTROL.md)。
- 旧完整 ribbon/options、原生辅助功能、三端 IME/DPI 和系统集成留至 M8；未把命令目录占位项计为实现。
- 本机验证 Windows x64。macOS/Linux 流水线配置保留，未取得本轮三端原生运行证据。GPU 完整帧时间与端到端输入延迟仍未认证。
