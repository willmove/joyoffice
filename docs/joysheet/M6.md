## 实现与演示

1. 解压 Windows 包，双击 `Open drawing workflow.cmd`。样例同时包含图表、嵌入图片、椭圆、中文文本框和迷你图。
2. 用「插入与绘图」创建图表或对象。图表共享原有布局引擎；修改 B2 会更新图表。形状包括矩形、圆角矩形、椭圆、三角形、线和箭头。已有墨迹可绘制；图标使用 GPUI Kit 内的 Lucide 名称映射。
3. 点击图表、图片或形状，拖动移动，拖动右下角控制点调整大小。在「图片、形状与对象 → 已选对象属性」修改尺寸、锚定、文本、颜色和层次。Delete 删除，Ctrl+Z/Y 撤销/重做。文本编辑使用文本框属性表单。
4. 「页面与打印」提供纸张、方向、打印区域、缩放、重复标题、页眉页脚和常用边距。Ctrl+P 打开真实 PDF 页面预览；左右键或 PageUp/PageDown 翻页，Esc 关闭。预览独立持有键盘焦点。
5. 预览中可选择导出 PDF，或打开系统打印对话框。Windows 需安装 PowerShell 7；PDF 预览使用系统 Windows.Data.Pdf，不需要另外安装 PDF 阅读器。系统打印通过 WPF FixedDocument 分页并显示原生 PrintDialog，只有确认后才调用打印队列。

开发、构建及回归：

```powershell
pwsh -File scripts/dev.ps1 run --locked -p joysheet -- --sample sales
pwsh -File scripts/dev.ps1 build --release --locked -p joysheet -p joysheet-cli --features joysheet/automation
pwsh -File scripts/dev.ps1 xtask ci
pwsh -File scripts/dev.ps1 xtask smoke --stage M6
pwsh -File scripts/dev.ps1 xtask dist
```

单项检查使用 `scripts/desktop-smoke.ps1 -M6Task 1` 至 `-M6Task 4`，均先执行已有 M3 场景；统一 M6 smoke 还运行 M4/M5 回归。打印后端独立检查入口为 `scripts/print-backend-smoke.ps1`。

## 验证与边界

分项构建、实际 GPUI 合成输入和 GPU 截图已覆盖图表插入/数据变化、对象绘制、拖动/缩放、属性、删除/撤销、保存及 XLSX 重开、页面设置、PDF 导出和预览。图表/对象截图与实际 PDF 页面均进行了视觉检查。测试发现并修正了打印表单将 A1 选区误当打印区域的问题。

图片仅在可见区域后台解码，同时最多 2 个任务，单图解码预算 64 MiB；屏幕缓存最多 16 张、各不超过 1024×1024 像素。打印和保存继续使用原始图片。对象拖动只在松开时发送一条引擎命令，并检查文档、工作表和版本，避免把拖动写入其他视图。

预览最多支持 32 页，超过会提示缩小打印区域或直接导出 PDF。Windows 打印采用 1200 像素宽的页面栅格，打印质量不等同于直接矢量 PDF；可导出 PDF 后通过阅读器进行高质量打印。macOS/Linux 预览依赖 Poppler，系统打印通过 PDF 查看器，尚无三端原生证据。

打印检查实际创建了 WPF 分页并观察到标题为“打印”的原生窗口，随后仅终止测试拥有的辅助进程；**没有把强制清理算作取消成功，也没有提交实体或虚拟打印任务**。取消、队列提交、设备边距/纸张和多份打印需人工验收。Windows 主程序依赖 VC++ x64 运行库，打印另需 PowerShell 7。

仍有明确边界：旋转图表文字、复杂形状字体/富文本/文字轮廓、旧图标全集的精确映射、多对象直接选择/排列、冻结边界的复杂叠放待进一步收敛。常用 PNG/JPEG 已验证；其他图片编码按解码能力报错。CPU paint 数据不代表 GPU 呈现帧时间，未认证性能门槛。
