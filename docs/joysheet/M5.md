完整 CI：1,351 项通过，1 项原有计时测试跳过；引擎层新增原子验证提交与非破坏预览测试，表单适配新增排序/去重回归。原 GridCraft 核心实现未因本轮修改。

UI 流程：点击“数据” → 数据整理/表格与验证/大纲/导入入口；导入窗口可选择本地文件或粘贴多行数据，预览最多显示前 20 行、10 列，每项文字截断至 256 字符。预览使用临时 Session，不向当前文档写入。表单仍保留高级参数以兼容复杂规则和多键排序。

已知边界：基础图标符号覆盖常见箭头/交通灯；其他图标集尚未完成逐像素匹配。警告和信息型验证显示消息并接受输入，未加入二次确认。查询结果最多列出 200 项。导入预览仍完整解析源文件，大文件操作会占用引擎队列；未取得 macOS/Linux 原生验收和新的 GPU 帧时间认证。

原项目的“连接”能力实际为导入表清单及 CSV/TSV/JSON、本地文件/表区域导入，不含持续外部数据库连接或自动刷新。本轮迁移以这些实际能力为范围。

## 测试包试用

解压 `joysheet-0.1.0-M5-alpha-windows-x86_64.zip`，双击 `Open data workflow.cmd`。内置样例 `docs/samples/M5-workflow.xlsx` 含整理后的原表、CSV 导入表与 JSON 导入表。

在 Sheet1 的 C2 输入 999 会触发停止型验证，保留草稿；改为 50 可提交。点击表头小三角或“数据”入口测试筛选，在“表格、条件格式与验证”“分组、大纲与窗格”“导入与连接”中试用对应表单。导入表单支持本地文件选择和多行文本，预览不会将导入数据写入当前工作簿。

`cargo xtask smoke --stage M5` 同时运行 M4/M5 场景。分项记录在 `docs/evidence/M5-1.json` 至 `M5-4.json`；完整 CI 摘要、Release 包回归及统一 smoke 摘要收录在同一目录。

最终 Release 可执行文件从 ZIP 解压目录运行，完整 M4Task=4 / M5Task=4 回归已通过；结果见 evidence/M5-report.json。交互输入执行验证，粘贴及程序化写入保留原引擎语义，可通过无效数据检查核对。
