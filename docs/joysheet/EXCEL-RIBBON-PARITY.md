# JoySheet / 本机 Excel Ribbon 比对

日期：2026-11-11。开发分支：`feat/joysheet-excel-ribbon`，基线 `4c7a951b73e62fcc3b71bbb7acc83abc99efa291`。

参照为本机中文 Microsoft Excel，文件版本 **16.0.20527.20150**。本次通过原生窗口实际打开文件、开始、插入、绘图、页面布局、公式、数据、审阅、视图、帮助，逐页截图；未读取或移植 Excel 实现、图标或其他私有资源。JoySheet 使用已锁定的 GPUI Kit / Lucide 图标资源，保留自己的品牌和命令协议。

## 比对与调整

| 选项卡 | 修改前差异 | 本次实现 |
| --- | --- | --- |
| 文件 | 仅有横向新建、打开和保存按钮 | 左侧后台导航、空白工作簿、最近文件、信息、保存/另存、打印、导出、关闭和选项；Esc 返回编辑 |
| 开始 | 文字按钮为主；缺样式、编辑分组 | 剪贴板、字体、对齐方式、数字、样式、单元格、编辑七组；大图标/两行格式按钮/三行小按钮；格式刷与宽屏两行单元格样式图库；字体、字号、边框、颜色、合并、数字格式、填充、清除、排序、查找等下拉菜单；活动单元格格式反馈 |
| 插入 | 图表和插图混在一组，缺少直接入口 | 表格、插图、图表、迷你图、筛选器、链接、批注、文本、符号；直接打开实际引擎能力对应的表单和菜单 |
| 绘图 | 没有选项卡，也没有原生笔迹输入 | 新增选择、橡皮擦、黑/红/蓝笔、黄色粗笔、墨迹转形状；拖动实时显示笔迹，落笔生成引擎墨迹对象；撤消/重做、擦除和 XLSX 保存重开 |
| 页面布局 | 只有页面设置和打印按钮 | 主题、页面设置、调整为合适大小、工作表选项、排列；纸张方向/大小、页边距、打印区域预设，以及打印标题、分隔符、缩放等表单 |
| 公式 | 函数库、定义名称和计算只有少量入口 | 函数分类与搜索选择器，插入可编辑公式；最近使用函数来自引擎实际记录；定义名称、公式审核、计算；审核结果和监视结果可见 |
| 数据 | 缺导入、查询、分级显示等分组 | 获取和转换数据、查询和连接、排序和筛选、数据工具、预测、分级显示、分析；补齐降序、分列、快速填充、模拟分析、分组等入口 |
| 审阅 | 仅新建批注、显示笔记和工作表保护 | 校对、辅助功能、批注、注释、保护；拼写、同义词、统计、批注导航、笔记与工作簿保护等已有能力可直接访问 |
| 视图 | 窗口和显示混排，只有首行冻结 | 工作簿视图、显示、缩放、窗口；冻结当前单元格以上/左侧、首行/首列和取消冻结；网格线、标题、编辑栏；修复隐藏标题后的实际绘制与命中 |
| 帮助 | 没有选项卡 | 本地使用说明、快捷键、绘图和格式刷说明、命令搜索 |
| 自动化 | 原有脚本入口放在“更多选项” | 保留产品扩展选项卡，直接访问脚本清单、录制、新建脚本和桌面控制；本机 Excel 默认未显示此选项卡 |

功能区支持横向滚动、Ctrl+F1 折叠、选项卡键盘切换、按钮可访问名称、格式设置启动按钮，以及中英/亮暗主题。共享样式库和其他产品未修改。图标来源采用本仓库已有依赖，新增的完整资源注册也修复了原来新增图标无法显示的问题。

## 明确保留的差异

这次完成的是 Ribbon 重排和列出的交互补齐，**不是 Excel 全功能或像素级等价验收**。

- 第二轮已补齐 SmartArt、WordArt、日程表、嵌入对象和独立公式对象的受支持子集，按钮已接入实际编辑；范围、文件格式和未覆盖项见[对象与分页记录](STRUCTURED-OBJECTS-AND-PAGING.md)。本机续验已修复缓存注册、Package 数据及预览图保存/重开问题；最终样例无修复打开、另存、关闭重开通过，见[本机续验](validation/20261111-excel-live/README.md)。
- 本机 Excel 的在线共享、账户、Office 加载项、联网翻译、3D 模型、屏幕截图、墨迹转数学公式/重播等未接入。JoySheet 的导入/连接继续遵守原有本地文件及非持续数据库连接的边界。
- 第二轮已接入纸张分页编辑、页眉页脚命中编辑和分页断点拖动；标尺、页边距拖动及完整上下文功能区仍未覆盖。
- 第二轮已补网格追踪箭头、逐级展开、移除及修订刷新；跨表双击导航尚未覆盖。监视窗口仍使用结果/参数面板。独立滚动拆分和持久对象组合继续保留原迁移矩阵中的限制。
- 字体/颜色/图表等使用 JoySheet 自己的菜单和表单；没有复制 Excel 的完整图库、账户模板和全部弹出框样式。黄色粗笔不等价于 Excel 的透明荧光笔。
- 截图和原生合成输入回归不等价于人工逐项业务验收，也不替代真实 IME、读屏、多显示器/物理 DPI、打印设备或其他平台验证。

## 可重复验证

```powershell
pwsh -File scripts/joysheet/dev.ps1 xtask check joysheet --validation
pwsh -File scripts/joysheet/dev.ps1 xtask build joysheet --validation
python scripts/joysheet/ribbon-smoke.py --output artifacts/joysheet/excel-ribbon-new-run
python scripts/check_docs.py
```

`ribbon-smoke.py` 要求输出目录尚不存在，启动隔离配置的原生 GPUI 进程，使用生产指针/键盘事件与 GPU 读回，最后只结束自己启动的进程。它覆盖全部选项卡、文件后台、格式刷、折叠、函数选择、隐藏标题后的编辑、笔迹/擦除/撤消和磁盘 XLSX 独立重开。第二轮脚本还覆盖结构对象表单、双击编辑与提取、日程表、分页编辑/拖动和追踪箭头。单元测试另外验证选择性粘贴值/格式的不同效果及撤消、页面设置预设、符号插入和表单参数转换。

本轮原始截图、可访问树、运行日志和逐轮报告保存在本机 `artifacts/joysheet/excel-ribbon-20261111/`。文件后台原始参考截图含最近文件信息，仅在该忽略目录本地留存。提交的比对图仅包含 Ribbon 裁剪，不含账户或最近文件。最终运行结果和截图见[验证记录](validation/20261111-excel-ribbon/README.md)。
