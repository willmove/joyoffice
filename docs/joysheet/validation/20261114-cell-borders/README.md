# 单元格单线边框修复（2026-11-14）

## 问题与实现

用户提供的 XLSX 中相关边框为 `thin`，没有 `double`。原屏幕绘制将每个单元格的四边向内缩 1 个逻辑像素，相邻单元格因此形成两条分离的线。

移除边框几何的内缩，四边与斜线使用实际单元格矩形端点；仍在所有背景填充之后绘制，并保留现有窗格裁剪、像素对齐和边框线型处理。未变更工作簿模型、导入、保存或 PDF 代码。
