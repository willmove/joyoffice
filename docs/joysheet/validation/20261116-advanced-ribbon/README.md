## 本次实现

| 原差异 | 本次更新 | 边界 |
| --- | --- | --- |
| 字体菜单只有固定样例 | 枚举本机已安装字体；格式字体页加入字形列表和实时示例 | 字体菜单尚无 Excel 最近字体分组和字体搜索 |
| 填充/字体颜色为文字菜单 | 主题色及深浅色、标准色、自动/无填充；其他颜色标准/自定义页、RGB/十六进制联动、新旧颜色示例；主按钮重复上次选择 | 标准色仍采用网格，未仿制 Excel 六角蜂窝与 HSL 色域控件 |
| 边框只有六个文本参数 | 线型、颜色、无/外框/内部预置及可点击边缘/斜线/内部线预览 | 预览线型仅覆盖当前引擎支持子集；不是 Excel 原生窗体像素复刻 |
| 外框操作可能给选区每格画外框 | 使用已有边框命令的选区周边语义，字体等修改和边框合为一次撤销 | 新内部批处理只允许格式及已知边框预置 |
| 表格样式直接进入参数表 | 60 个实际引擎样式按浅/中/深分组，缩略图使用引擎配色；选择后进入建表区域/标题确认 | 配色遵循本项目表格样式实现；不声称与 Excel 每个内置样式完全同色 |
| 图表、形状、SmartArt 仅输入类型代码 | 增加可视选择，点击保留参数，取消不插入对象 | 只展示引擎实际支持的类型；图标示意不等于 Excel 全部图库/实时预览 |
| 多级排序需手写后续排序键 | 可添加、删除、复制、上移/下移条件；按表头选择列，设置依据和顺序，支持方向/大小写 | 未实现 Excel 任意自定义序列编辑器；颜色按已有引擎排序语义处理 |
| 分列一次提交，无数据预览 | 三步向导、分隔符与限定符、固定宽度字符标尺、逐列格式、目标区域；支持文本保留前导零、跳过列、六种日期顺序 | 高级数字小数/千位分隔符选项与覆盖现有数据确认仍有差异 |
| 导入预览关闭窗口并转为侧栏结果 | 留在导入窗口显示有行列的只读样本；预览使用隔离引擎会话；取消或修改参数后丢弃过时预览结果 | 本地文本/CSV/TSV/JSON 子集，不包含完整 Power Query 变换编辑器 |
| 名称管理器是右侧卡片 | 居中名称/值/引用/作用域/注释表；新建、编辑、删除确认；编辑后返回管理器 | 暂无 Excel 全套名称筛选器 |
| 条件格式管理只显示结果 | 居中规则管理器、当前选区/工作表范围、规则草稿、新建/编辑/删除/排序、如果为真则停止、应用/确定/取消 | 未覆盖重复规则按钮和全部图标阈值编辑选项 |
| 规则编辑重建已有格式 | 保留未编辑的自定义样式、主题颜色、阈值、显示值和平均值选项；公式仍经引擎校验 | 新增条件格式以现有引擎支持范围为限 |
| 点击打印立即弹出系统窗口 | 先打开设置和实际 PDF 页面预览；纸张、方向、页边距、缩放修改后重新生成；打印按钮再打开系统打印窗口 | 打印机、份数、双面等设备选项仍由系统对话框承担 |

预览和实际分列共用解析器。新增逐列格式保留、输出边界检查与原子回滚；规则管理一次应用对应一次撤销，取消不写工作簿，写入时检查文档/工作表/修订。名称和规则模态窗口限制焦点；弹出菜单优先处理 Escape 和导航键。
