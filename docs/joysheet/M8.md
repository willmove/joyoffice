## 试用本次 Windows 包

1. 解压 `joysheet-0.1.0-M8-preview-windows-x86_64.zip`，运行 `Open sales sample.cmd`；也可通过同名 `-setup.exe` 用户级安装。无需 Rust 和原 GridCraft 目录，包保持未签名。
2. 在“设置”（Ctrl+,）切换主题、语言、公式栏和自动保存；拖动列标题边界、工作表标签，确认宽度及顺序变化，Ctrl+Z 撤销。
3. 在 Sheet1 输入 `=SUM(1,2,3)`，保存/重开；使用跨表引用选取时，草稿保持所属工作表。数据验证为警告时，取消继续编辑，保留按钮才提交。
4. 使用高级样例测试透视、保护、脚本与信任；脚本从磁盘重开默认未信任。更多流程见 M4–M7 交付记录。
5. 设置中开启恢复副本（默认开启）；未保存修改和草稿每 5 秒写入用户配置恢复目录。崩溃后从“恢复副本”选择记录，恢复为独立未保存文档，确认后另存为。正常关闭并放弃不会留下本会话副本。副本不替代显式保存和文件备份。

Windows 系统打印需 PowerShell 7（不捆绑），PDF 预览使用内置 WinRT 渲染器；macOS/Linux 预览需 `pdftoppm`。PDF 导出可直接使用。高 DPI/系统 IME/外部剪贴板互操作、打印队列和读屏需要真实设备专项。

## 未完成验收与功能边界

- 环境门槛：缺少 macOS 15 arm64、Ubuntu 24.04 图形主机；无远程仓库以派发三端 CI。已有两端打包代码和流水线，不能据此记为构建或原生运行成功。
- 发行门槛：未提供发行者证书、Apple 公证身份、更新 feed 与发布远端；本次只交付 Windows 未签名可测预览包。
- 性能门槛：记录 CPU 绘制和提交到引擎/CPU paint 的编辑响应；未取得 GPU 呈现帧时间与物理输入延迟，不宣称已达 60 FPS 门槛。
- 界面边界：Windows W1–W4 已补齐旋转文字、复杂边框/图案、形状文字、多对象选择与批量操作、原生窗口排列和常用键盘区域导航，见 [WINDOWS.md](WINDOWS.md)。更多复杂文档视觉检查、真实读屏和系统输入仍需专项。
- 上游边界：单条长命令不能中断；拆分窗格沿用冻结语义；持续数据库连接不属于原有实现。恢复最多扫描 128 条、单副本上限 256 MiB，超大工作簿应显式保存。

因此 M8 总验收仍开放，`BUILD.json` 的 `milestoneComplete` 保持 false。不能把本次预览交付写成“全部迁移完成”。

测试机见 VALIDATION.md；同一 Windows 图形会话、Release automation 构建，顺序打开 10k/100k 行 × 20 列 CSV，各滚动 60 次，再执行 30 次低依赖公式编辑。报告：[M8-performance.json](evidence/M8-performance.json)。
