# 可复制的第二轮启动提示

仅在用户／C08 确认唯一负责人并准备好独立目录后发送。把提示中的“填入”换成实际值；三个执行者都使用同一个已交付的协作包完整 SHA。这里没有自动启动或代发授权。未填值、负责人冲突、目录／分支不符时先报告，不在错误目录开始修改。
