# W04：平台与参考环境证据（可选）

分配：空闲主机上的一个 Agent；分支 codex/w04-reference-validation。每次只有一个负责人；多主机要同时写证据，由协调者另分 W05/W06，不共用 W04。

## 目标与范围

补 T004/T005/T001 实测证据。按本机能力至少选一项，不为凑齐环境停等：

- 平台：记录系统/架构/显示服务/GPU/驱动/字体/IME，按现有 README 构建并真实运行窗口。Linux 区分 X11/Wayland，统信/麒麟记录发行版/ABI。只读运行，不擅自安装系统组件。
- Office：在 scratch 目录复制 5 个既有 DOCX，用实际 Word/WPS 打开，记录正文/修复提示/保护状态，人工导出参考 PDF，记录完整版本、字体散列/face、页面/导出设置。规定参考 Word 是 Office LTSC 2024；其他版本仅探索证据。
- 几何：用已有 compare_pdf_lines.py --dump 提取参考 PDF，记录抽取器版本/命令。完整 DOCX 排版未接入，不能把缺候选说成比较通过。
- 外链样例不点击/授权访问；采用软件可提供的离线/受保护路径。不确定的网络行为只记录观察边界，不能声称隔离已验证。

## 文件边界

只新增 docs/coordination/evidence/W04/** 和 docs/coordination/reports/W04.md。仅提交原创/授权明确的证据；不提交用户文件、凭据或系统字体。不改语料/清单、比较器、CI、产品文档或代码。GUI 先与用户约定时段。

## 验收与交接

每项证据含 tested revision、时间/时区、完整版本、命令/步骤、实际结果、失败/未验证分类。缺硬件/软件报告准确环境缺口。运行 python3 scripts/check_docs.py，提交/推送自己的分支，由协调者登记正式状态。
