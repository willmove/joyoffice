### 公开接口和断点契约

```rust
pub fn layout_paragraph(
    font: &LoadedFont,
    text: &str,
    size: Emu,
    features: FeatureSet,
    width: Emu,
    breakpoints: &[usize],
    limits: LineLimits,
) -> Result<ParagraphLines, LineError>;

impl LayoutLine {
    pub fn to_glyph_run(&self, origin_x: Emu, baseline_y: Emu) -> GlyphRun;
}
```

新增导出类型：SourceRange、ClusterRange、LayoutLine、ParagraphLines、LineDiagnostic、OverflowKind、LineLimits、LineLimit、LineStats、LineError、BreakError。

- 调用者负责提供语言规则允许的断点。本模块不生成 Unicode/中文禁则断点，也不宣称实现 UAX #14 或 Word 规则。
- 断点是严格递增的 UTF-8 byte offset，范围为 1..=text.len()；段尾可以提供，也可省略，由实现补足。空段要求空断点集合。
- 不在 UTF-8 字符边界、重复/逆序/零点/越界、位于整段整形 cluster 内的断点，均返回 InvalidBreak；不隐式修正或按字符数估宽。
- 每次断行之后重新整形剩余文本，并过滤进入新 cluster 内的候选断点。最终端点仍只取调用者集合或段尾，不添加应急拆字断点。
- 每个候选行使用既有 shape 按相同字体、字号和特性独立整形。整段/剩余全文的整形结果只在该全文本身成为候选时复用；不切片整段字形作为行字形。
- 从最远端点开始检查，选源位置最远的可容纳候选，不假设候选宽度单调，不做最优折行/齐行。没有候选能容纳时，输出最短合法完整 span，保留实际超宽几何；SingleCluster 和 UnbreakableSpan 分开诊断。
- 空段输出一行空 ShapedRun；连续、前导和尾部空白原样保留，不裁剪，不静默截断。组合字符、连字、emoji 按既有 shaper cluster 处理。emoji 缺字可以诊断，但不承诺彩色字体或完整 UAX #29 grapheme 分析。
- 零/负宽度报错；字号限定为 1..=1_000_000_000 EMU。控制字符、硬分隔符、双向格式控制及 HarfRust 对逐 scalar 猜测为 RTL 的脚本拒绝；调用者仍须保证输入是横向 LTR，本检查不等于 UAX #9。
- EMU width 是字形 advance 总宽，不是墨迹包围盒；校验 cluster 顺序、字符边界、非负 advance、累加位置和宽度一致性，异常返回 InvalidShaping。

### 源/字形范围与场景

SourceRange.bytes 和 .scalars 都是输入段落中的绝对半开区间。scalar 是 Unicode scalar value，不是 grapheme 或 UTF-16 单位。各行连续覆盖输入，非空段每次至少推进一个安全 span。

LayoutLine.run 保留 LoadedFont 的 FontKey、字号、原文及 EMU 字形几何；其中 ShapedGlyph.cluster 仍为行内 UTF-8 byte offset。ClusterRange.glyphs 是该行 run 的局部 glyph 半开区间，ClusterRange.source 则映射回段落绝对 byte/scalar 区间。不同上下文的整形 cluster 不宣称一一等价。

to_glyph_run 复用 GlyphRun::place，不重新整形；调用者提供原点和基线，可加入现有 PageScene。示例按 A4/18pt 固定间距安排，仅演示转换，不是正式分页、布局快照或 Word 行距。

### 计算预算与诊断

默认值也是不可由调用者提高的硬上限；可按请求降低：输入 65,536 bytes、4,096 个调用者断点、8,192 次 shape、累计 16 MiB 整形输入、4,096 行、128 条诊断。LineStats 记录整段/剩余文本探测与候选的实际 shape 调用和输入字节数。

预算耗尽返回 LimitExceeded，整个请求失败，不返回伪成功的部分段落。超宽与缺字诊断按选中行的原文绝对范围给出；达到诊断上限后记录 omitted_diagnostics，行文本、字形和 ShapedRun.missing 不丢弃。该贪心实现有界，但尚未通过产品级长文性能验收或不可信字体 fuzz 验收。

### 独立实现来源

依据公开规范和现有通用整形库接口实现；没有搬运 Word/WPS/Zed 排版实现。

- [UAX #14 revision 57，§1](https://www.unicode.org/reports/tr14/tr14-57.html)：区分断点机会与可用宽度下的实际行拟合。本切片只做后者，不作 Unicode 断行符合性声明。
- [HarfBuzz cluster model](https://harfbuzz.github.io/working-with-harfbuzz-clusters.html)：整形 cluster 可能合并多个字符/字形，不能按输入字符等分；LTR cluster 单调性用于安全范围映射。
- 现有精确固定的 HarfRust 0.8.4 UnicodeBuffer/Direction，以及项目 shape/ShapedRun 接口；不改变其 feature 或 cluster 处理。
