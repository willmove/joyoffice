## 变更与边界

W05 只允许默认格式纯文本正文段落做拆分／合并／插入／删除。W12 落实 [W05 提案 3(a)](W05.md)：当受影响段落的 pPr／rPr **能证明完全映射**时，结构导出**原样复制源属性元素字节**；不能证明时返回 `ExportError::Unsupported`，不静默丢掉格式。不靠样式名猜测生成新的属性树。

无硬依赖 W10。W10 并行改 `export.rs` 的 `ExportPlan` 来源绑定；本任务没有改 `ExportPlan` 字段，也没有改 `plan_export` 末尾组装计划的那段。合入顺序仍是先 W10 再 W12（或 rebase）。

### 支持矩阵

结构编辑仍按身份对齐，不按文本相似度。拆段时前段保留原身份与 `SourceRef`，后段是无来源的新身份；合并保留第一段。默认格式段落仍走 W05 的 `plain_markup` 与新段落序列化（`<w:p/>` 或单个 `w:r`），字节行为不变。

非默认段落只有在下列条件**全部**成立时才允许结构编辑：

- 段落、段落标记、每个 run 都没有保留片段；没有注释或处理指令；没有内联（含 `w:br`）。
- `w:p`／`w:r` 属性只使用 W05 已允许的 rsid／w14 标识；其余未知属性仍拒绝。
- `pPr` 无属性、无 `sectPr`，子元素只属于 importer 已映射的叶子、一个 `numPr`、至多一个标记 `rPr`。`props::para` 判定 `complete`，且映射结果与模型的样式、`ParaProps`、标记 `RunProps` 相等。
- run 内至多一个 `rPr`；`props::run` 判定 `complete`，且与对应模型 run 的样式和属性相等。`proofErr`、`lastRenderedPageBreak`、空 `w:r` 仍允许同格式文字补丁，但禁止会丢掉它们的 run 重建。
- 被复制的 pPr／rPr 里出现的前缀，必须能从 `document`／`body` 的声明、或被复制元素自身的声明解析。只写在 `w:p`／`w:r` 上的前缀不能带到 `w:body` 的兄弟位置，整次结构编辑拒绝。

已映射并允许复制字节的范围（与 `props::para`／`props::run` 的完整映射一致，且属性名用白名单，多出来的属性拒绝）：

| 容器 | 子元素 |
| --- | --- |
| pPr | `pStyle`、`jc`、`ind`（start/left、end/right、Chars、firstLine、hanging）、`spacing`、`outlineLvl`、`numPr`（仅 `numId`+`ilvl`）、`keepNext`／`keepLines`／`widowControl`／`pageBreakBefore`／`snapToGrid`、一个标记 `rPr` |
| rPr | `rStyle`、`b`／`i`／`strike`／`vanish`（含显式 `w:val="0"`／`"true"`）、`u`（仅 `w:val`）、`sz`、`rFonts`（具名与 theme、hint；同一槽不能同时有 theme 与名字）、`color`（仅 `w:val`）、`lang` |

| 编辑 | 结果 |
| --- | --- |
| 完全映射段落的拆分（段首、段中、段尾）、合并、空段插入、整段删除 | 支持。新段与重建后的 run 内嵌**源 pPr／rPr 元素字节**，不是重新序列化 |
| 一段内粗体与斜体相邻，从中间拆开 | 两侧各自保留原来的 rPr 字节；段落 spacing 留在两侧的 pPr |
| 同一次合并需要两种 rPr（例如斜体段并入粗体段） | 支持。重建时按已登记的源 run 查找字节 |
| 默认格式与带格式混合的文档 | 只结构编辑能证明安全的段落；不安全段落的字节原样留下 |
| 中文、emoji ZWJ、组合字符、tab、XML 特殊字符写在带格式 run 里再拆段 | 支持。尾段继续使用该 run 的 rPr 字节 |
| `ns0` 前缀，以及元素走默认命名空间、属性仍用 `w:val` | 支持，属性字节被复制 |
| DOCX-MIN-002 标题（唯一属性是已映射的 `w:pStyle`） | 拆分成功，新段复制该 `pStyle` 字节 |
| 同预算重新导入 | 检查文本、属性、节位置、保留片段多重集合，与 W05 相同 |
| 计划不可变；拒绝不改 backing；部件预算过紧 | 返回 `ExportError::Budget`，不写出 |

新段落不复制源 `w:p` 的 rsid／`w14:paraId`。存续段在 run 分组未变、或拆段后只是前缀缩短时，仍走 C02 文字叶片补丁，pPr／rPr 字节不动。run 分组增加或属性变化时才重建该段内部：保留 `w:p` 起始标签，复制该段自己的 pPr 字节，再按相邻且属性相同的 run 分组写出复制来的 rPr。

查找模板优先用 `Arc` 指针相等（`split_off` 会克隆这些 `Arc`），其次才按值相等。没有对应源字节的新格式（`FormatText`、`FormatParagraph`，或给没有源 pPr 的新段手写样式）仍然拒绝，原因字符串仍是 `new paragraphs require default paragraph and character properties` 或 `character formatting has no fully mapped source properties`。

### 拒绝矩阵

不能证明就拒绝。既有保护、签名、书签锁定、移动／重复／伪造来源、预算与往返失败的变体不变。

| 情形 | 原因 |
| --- | --- |
| 高亮、底纹、`w:bCs`、`w:position`、非法 `jc`、主题色、下划线颜色、同一 `ind` 两种拼写、未知子元素（importer 记为保留片段） | paragraph holds preserved markup |
| 已映射元素上多出的属性（如 `w:jc` 带 `w:extra`） | structural paragraph markup has unknown attributes |
| 前缀只声明在 `w:p` 或 `w:r` 上 | property markup uses a prefix that cannot be copied safely |
| `w:br` 及其他内联 | paragraph structure edits require default paragraph and character properties |
| 节结束段（含同时带 jc 的节段） | paragraph ends a section |
| 注释、处理指令、未知 `w:p`／`w:r`／`w:t` 属性、未映射直接字符 | 沿用 W05／C02 的原因 |
| 没有源属性字节的格式修改 | new paragraphs require default paragraph and character properties；或 character formatting has no fully mapped source properties |
| 重建会丢掉 `proofErr`、`lastRenderedPageBreak` 或空 run | structural run rebuild would drop proofing or cached break markup |
| 映射结果与模型不一致 | mapped paragraph properties do not match the source model |

节检查现在在格式检查之前。原先“带格式且结束节”会报默认属性那条；现在报 `paragraph ends a section`。仓库里没有覆盖这个组合的既有断言。

### 与代码事实的差异

任务卡写“原样复制源 XML **属性**字节”。实现复制的是已证明安全的 **pPr／rPr 元素字节区间**（含子元素），不是逐个属性重写。这样未知但已被白名单接受的属性顺序与空白得以保留，也避免靠样式名重造属性树。

`w:br` 在模型里是 `InlineKind::Break`，不是保留片段。本切片不迁移断行（提案 3(c)），所以仍用 W05 的默认属性拒绝串，避免改既有 `w:br` 断言的期望字符串。
