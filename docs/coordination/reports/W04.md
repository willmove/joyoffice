## 可复现命令

实际构建使用协调者自己的共享构建缓存，不修改 W01/W03 目录：

```sh
CARGO_TARGET_DIR=/Users/willm/.codex/worktrees/agent-coordination/joyoffice/target cargo build -p joyword --features dev-runtime-shaders --locked
JOYWORD_REQUIRE_TEST_FONT=1 JOYWORD_TEST_FONT='/System/Library/Fonts/Supplemental/Songti.ttc:0' JOYWORD_LINE_LATIN_FONT='/System/Library/Fonts/Avenir Next.ttc:0' cargo test --locked -- --nocapture
cargo clippy -p joyword-docx -p joyword-layout -p joyword-pdf --all-targets --locked -- -D warnings
textutil -convert txt -stdout tests/fixtures/docx/DOCX-MIN-001.docx
```

textutil 同样对 MIN-002…005 执行，完整输入散列/命令/文字保存在 textutil.json。

重现诊断 PDF（最初生成在证据目录，检查后移到忽略的 target 保留；下列路径适用于后续重现）：

```sh
cargo run -p joyword-pdf --example unified_scene --locked -- '/System/Library/Fonts/Supplemental/Songti.ttc' 0 target/w04-validation/unified
python3 scripts/verify_unified_pdf.py target/w04-validation/unified
pdftoppm -singlefile -scale-to 1500 -png target/w04-validation/unified/scene.pdf target/w04-validation/unified
pdfinfo target/w04-validation/unified/scene.pdf
```

另用 bundled Python/pypdf 独立提取全部页文字，与 expected.json 去空白比较通过，结果见 unified/pypdf-readback.json。字体完整散列与 face 见 environment.json；没有将系统字体或其嵌入子集提交到远程仓库。
