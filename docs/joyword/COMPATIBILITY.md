# 格式、功能与兼容矩阵

版本 0.2 · 2026-10-13。本文是承诺范围与验收方法；当前实现状态以 [IMPLEMENTATION](IMPLEMENTATION.md) 为准。**目前没有任何 Office 格式被认证为完整支持。**

## 1. 两个维度的状态

功能等级：完整支持、部分支持、保留支持、不支持。验证状态：unverified、pass、fail。对尚未实现的能力使用“未实现／unverified”，不误称已经实现了安全拒绝。

每条兼容记录至少包括：功能 ID、格式／profile、读取、显示、编辑、写回、转换、交互、子集说明、限制、样例 ID、参考软件版本、字体散列和证据。支持声明绑定到某个源码修订，不随文档计划自动升级。

## 2. 格式路线

| 格式 | 早期行为目标 | 后续目标 | 主要损失／风险 |
| --- | --- | --- | --- |
| Transitional DOCX | M1 明确子集读写；其余检测和保留 | M2 日常、M3 审阅、M5 专业、M6 扩展 | 未知 XML、对象、关系、样式与兼容设置 |
| Strict DOCX | 识别后说明当前支持状态，不伪装为 Transitional | M6 对应命名空间及 profile 独立读写 | Transitional 专有结构不能直接写进 Strict |
| DOTX | 模板类型识别，原件保护 | M5 模板工作流、M6 完整格式映射 | 基于模板新建与直接改写模板必须区分 |
| DOCM／DOTM | 识别宏容器，不执行 | M6 原始宏与相关部件保留，安全编辑范围 | 转 DOCX 的宏移除必须提示；签名会受修改影响 |
| ODT | 1.0 内识别并明确提示未支持 | M8 ODF 1.3 双向，1.4 逐项扩展 | 样式、修订、注释、对象和分页语义不完全一一对应 |
| RTF | M2 剪贴板相关子集 | M6 文件双向转换 | 控制字、对象及复杂样式；不能忽略后宣称无损 |
| HTML | M2 剪贴板受限子集 | M6 文档双向转换 | CSS、脚本、外链与分页；导入不运行脚本 |
| Markdown／TXT | M1 可选纯文本输入入口不等于格式完整 | M6 双向转换 | 格式、修订、批注、对象、页面信息表达能力有限 |
| PDF | M0 单页输出验证，M2 普通导出 | M6 链接、书签、标签和页面图片；M8 归档（PDF/A）与重建 | 导出可检索；重建为近似，不恢复原 Word 语义 |
| EPUB／页面图片 | 无早期承诺 | 页面图片 M6，EPUB M8 | 重排式 EPUB 与固定分页不同；图片不保留可编辑语义 |
| DOC | 类型识别与安全拒绝先行 | M6 导入（1.0 范围），M8 写出 | 二进制变体、对象和加密；不能把扩展名改成 DOCX |
| WPS 文字（.wps／.wpt） | 类型识别与安全拒绝先行 | M6 导入（1.0 范围），保存为 DOCX | 无公开规范；DOC 兼容部分按 MS-DOC，WPS 私有流保留不解释；早期私有变体只诊断 |

PDF/A、PDF/UA 等合规声明必须通过对应验证器及语义检查；使用支持该标准的库不等于整份输出自动合规。

## 3. DOCX 元素与操作目标

| 功能组 | 最早实现 | 完整性门槛 |
| --- | --- | --- |
| 包结构、关系、内容类型 | M1 | 关系闭合，未知条目无编辑保存不丢失，路径和资源预算检查通过 |
| 段落、文字、空格和基本 run 格式 | M1 | 内容、空格、显式换行和格式读写一致；已知可编辑子集外内容有诊断 |
| 样式、主题、列表、多级编号 | M2 | 继承／重启／续接语义保留，复制粘贴不产生串号 |
| 表格、行内图片、页面设置 | M2 | 结构、资源与基本分页；复杂嵌套／绕排未实现时单独标识 |
| 修订和批注 | M3 | Word 与 JoyWord 双向交换，接受／拒绝和锚点行为正确 |
| 分节、多栏、跨页表格、浮动、脚注 | M5 | 页断点和对象几何达到固定语料阈值 |
| 域、目录、引用、公式、内容控件 | M5 | 公式结构可编辑，域代码与缓存值分别保留，重新计算有界 |
| 加密、保护、签名及宏容器 | M6 | 权限、失效和格式转换诊断正确；无自动执行 |
| 图表、SmartArt、复杂嵌入对象 | M8 | 原生编辑通过前只可声明保留／预览支持 |

M1 子集至少包含正文段落、文字、基本字符样式、基本段落对齐与页大小／边距；内容控件和跨段复杂域作为透明结构保留，锁定语义允许时可编辑其中文字。导入不支持的 XML 不能丢弃：能够建立局部保留边界时允许安全编辑，否则只读。M1 不要求解释已有修订，却必须识别危险情况并防止改写破坏它们；文档保护和打开即修订（trackRevisions）在审阅能力实现前只读打开或明确提示。M1 识别兼容模式：新文档写 15，既有文档保留原值。

## 4. 未知内容保留规则

| 情况 | 行为 |
| --- | --- |
| 完全无编辑 | 可以原文件复制；原始签名及压缩结构随原件保留 |
| 未触及的独立部件 | 保留解压后的内容、content type 和关系，不声称整个 ZIP 字节不变 |
| 已知 XML 内未知元素／属性 | 保留命名空间和上下文，针对所属节点追踪影响范围 |
| 修改未知对象依赖的编号／样式／关系 | 不能证明安全时阻止操作或生成显式另存方案 |
| 无法安全解析整个结构 | 只读／拒绝，保留原件；不能展示截断内容并默认覆盖保存 |
| 数字签名文档发生修改 | 告知签名失效；不保留“有效签名”的错误声明 |
| 用户选择有损副本 | 列出损失并绑定明确目标；正式原件默认不覆盖 |
| AlternateContent 的 Choice／Fallback | 编辑 Choice 内容后重新生成或删除对应 Fallback，不留下陈旧副本；未理解的分支整体保留并限制相关编辑 |
| AI 生成内容标识元数据 | 往返保留；不作为普通元数据清理 |

资源去重和 ID 重编号也属于可能影响保留内容的操作，不能作为无害优化随意执行。

## 5. 跨格式损失报告

ExportPlan 对每个受影响对象给出逻辑位置、源能力、目标表达方式和结果：精确保留、等价映射、近似呈现、扁平化、丢弃或拒绝。默认不会静默接受后四者。

典型项：修订是否变成最终文本、批注是否丢失线程、脚注是否移为尾注、字段是否冻结结果、公式是否变图片、浮动对象是否转行内、文本框阅读顺序是否改变、字体是否被替换、宏是否移除。导出后附报告或可保存的收据，不把隐私正文默认写入诊断日志。

## 6. 参考语料与测量

语料分为原创规范最小样例、原创组合场景、参考产品生成文件、明确授权且去敏的真实文件。不得通过从任意互联网下载用户合同来扩充语料。

每个文件登记：case_id、需求 ID、格式 profile、文件散列、来源授权、创建工具与版本、系统、locale、字体／打印设置、预期语义、预期几何、支持等级和证据路径。缺失参考产品或字体时标未验证，不能自动跳过后报告全部通过。

往返矩阵：Word → JoyWord → Word；JoyWord → Word → JoyWord；中文文档的 WPS 路径与 Word 并列验收，LibreOffice 作为补充对照。WPS 生成文件中的 wpsCustomData 命名空间、customXml 部件和数字样式 ID 列入识别与保留样例。PDF 至少用两个独立阅读器检视，文本抽取、链接与标签另行检查。语义一致不推出分页一致；分页一致也不推出修订数据正确。

DOCX 比较采用包内容与关系图规范化，避免 ZIP 时间戳等噪声；未知部件同时做字节／散列比较。几何比较固定字体与 profile，行／页断点必须一致，位置阈值见 [QUALITY](QUALITY.md)。

## 7. 当前矩阵更新原则

每个完成的格式任务必须追加真实验证记录，而不是修改本文件的目标阶段来暗示完成。当前产品仅为 M0 工程基础时，所有 DOCX／ODT／DOC／RTF 等格式能力仍是未实现／unverified。
