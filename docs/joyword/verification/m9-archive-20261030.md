## T900 / T901 规格审查

[实时协作](../COLLABORATION.md) 明确账户与设备、共享授权、局部 ID 的限制、
幂等确认、七类结构冲突、权限撤销、离线私有分支、崩溃恢复和服务运维。
人工规格审查逐条检查了双用户审阅、离线删除冲突、撤权后重连、确认前崩溃和旧备份恢复：
各场景都有前提、必须保留的数据和可观察结果。没有把本地稳定 ID 当作 CRDT，
也没有将现有 AI 授权等同文档上传授权。具体协议算法和性能预算留待下一轮立项确认。

[套件边界](../SUITE.md) 逐项审查 Word／Sheet／Deck 的独立模型、七类共享候选和六个交换场景。
公式转数值、幻灯片转图片、主题映射、缺字体与外链均明确实际支持等级、损失和拒绝行为。
现有 Word 模块继续保持所属责任；只有第二个真实消费者及契约测试齐备后再提取共享模块。

上述是静态文档场景审查；本轮没有运行不存在的协作服务或其他应用。
TASKS 的“后续规格获确认后定义协议测试”要求保持不变。两项交付物是规格入口，
有完整文档、场景审查和文档检查证据，因此可将入口任务改为 done。

## T806 实现与自动验证

文件菜单和原生命令注册表新增“导出 PDF/A-2b…”，中英文资源同步。
先显示 UTC 归档年份、字体嵌入许可及独立合规验证说明，再请求新的 PDF 路径。
取消不排队写入；确认期间换文档或版本变化则放弃导出。
这些窗口流程已实现，尚未通过真实 GUI 验收。

后台仍消费当前已稳定的同一 LayoutSnapshot 和实际字体字节／face，
通过 PdfProfile::PdfA2b 输出，使用已有 sync／读回／禁止覆盖发布。
归档路径额外拒绝遗漏的 opaque 对象；库验证器拒绝缺字和不允许嵌入的字体。
普通 PDF 和打印继续使用 Standard 配置。

新增应用入口回归检查：同一输入／年份确定性、XMP 归档标识、非法年份零输出、
旧文件保护、缺字零输出、遗漏对象零输出；原有过期布局拒绝同时覆盖归档类型。
首次回归使用的小型测试字体没有部分小写字形，正确触发 PDF/A 拒绝；
将确定性样例改为实际有字形的 A，并为缺字增加独立拒绝测试。
保留 [初始失败](../validation/20261030-m9/archive-initial-failure.log)，不把失败当通过。
