## PDF/A-2b

新增 `PdfProfile` 与 `render_with_profile`，普通 API 继续走原默认配置；归档复用相同 PageScene、字体字节／face、嵌入权限检查和位置化 glyph 路径，不另做分页。精确固定的 krilla 0.8.2 负责 PDF/A-2b 配置、ICC 色彩、XMP 和验证；失败不返回字节。归档创建年份显式提供，范围 1–9999，不读取系统时钟。没有新增或升级依赖。

```text
joyword-cli convert input.docx --to pdfa-2b --archive-year 2026 --font C:/Windows/Fonts/simsun.ttc:0 --output new.pdf
```

`--archive-year` 只允许与 pdfa-2b 一起使用。有遗漏块则拒绝归档；写入仍为 create-new，不覆盖原件或旧输出。JSON 的 independent_conformance_verified=false 表示导出器没有冒充外部验证器。PDF/A-2b 不表示 PDF/UA、A 级结构或完整阅读顺序合规。字体仍需具有允许相应嵌入／分发的许可，系统字体不随仓库或软件分发。

## EPUB 与可访问性

前轮未发现已安装阅读器；本轮在 C:/Applications 找到既有 SumatraPDF 3.6。原 EPUB 可显示中文、基础表格及 PNG，并可检索“编号”，但没有展示 EPUB 3 导航面板。新增可选 NCX，和 EPUB 3 nav 从同一有序标题列表生成，manifest／spine 显式关联；空标题列表仍有正文入口，不改变正文、图片或原 DOCX。

最终文件在 EPUBCheck 5.4.0 下 **0 fatal／error／warning**，见 [原始报告](../validation/20261030-archive/epubcheck-final.json)。独立阅读器原生树出现“第一章 阅读顺序”和“第二章 图片”，实际点击第二章通过；单页样例不证明多页远距离跳转。中文检索、表格 001 和蓝色图片可见。**阿文与 emoji 仍出现缺字**，完整混合文字阅读器验收保留 partial，不能将 EPUBCheck 零错误替代视觉通过。

格式对话框补稳定 accessibility id、Role::Dialog 与本地化标题。最终 JoyWord 原生树实际显示“对话框 字体”，子字段和复选框在其下；Escape 取消保留原文，原生关闭无新增错误。没有把这个角色修复等同于 Narrator／VoiceOver／Linux 完整读屏。观察与截图见 [GUI 证据](../validation/20261030-archive/gui/observations.jsonl)。
