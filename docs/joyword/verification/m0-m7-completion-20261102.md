## 本轮实现

- `joyword-shell::exchange` 提供纯内存、不可变字节的有界转换计划；CLI `exchange` 生产调用同一计划，先列损失再显式生成新文件。支持及拒绝范围详见 [文本格式交换指南](../guide/text-exchange.md)。
- DOCX 输出新增独立的新建文本投影接口，生成 A4 Transitional 包和兼容模式 15，逐项检查输入属性、XML／部件／包预算并经生产导入器复验；不代替原件保留保存。
- 拒绝默认公开隐藏文字、未决审阅、注释和不支持的复杂容器；解析样式后只投影当前声明的正文格式。输入／模型／语法／输出分别设限。
- 修复 UTF-8 BOM 和 UTF-16 BOM 损坏输入未计入丢失、UTF-16 奇数尾字节静默丢失，以及合法 U+FFFD 被误计为解码错误。
- 修复 Markdown 正文未转义导致字面符号变成语法；HTML 实体重复解码、数值引用缺失、head／title 元数据混入正文和格式化 HTML 空白生成伪段落。
- 修复 RTF 字体表进入正文、emoji 代理对丢失、截断／多余根数据被接纳、控制参数溢出、隐藏属性丢失与空段落丢失；旧代码页未经验证不再按 Latin-1 或 UTF-8 猜测。
- shell 新增两条内部格式库依赖，CLI 未引入 GUI 或网络。根锁只增加 shell 的两项已有内部依赖，没有升级注册表包。分层门禁逐边登记，文件 I/O 白名单只增加 CLI 的交换发布适配器。
