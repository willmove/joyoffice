# DOCX 打开性能优化

2026-11-01，Windows x86_64、Rust 1.98.1。基线为 `main` 的 `2fdef5b`，实现分支为 `codex/joyword-open-performance`。沿用前轮五份本机复杂表格文档；私有文档、路径、截图和运行日志不入库。

## 定位与实现

最初的分阶段计时显示，文件读取约 0.2–0.6 ms，首张 CPU 栅格化约 4 ms，耗时主要在 DOCX 导入和整篇分页。进一步的临时探针定位到大表格的命名空间查找：为每个单元格段落重建祖先作用域时，递归遍历了大量无关 XML 子树。修订版最后一张大表的构建约 167 ms。现在先按已校验的 XML 字节范围排除无关子树，只进入可能包含该段落的作用域；仍保留实际祖先上的命名空间、未知 XML 和局部锁。

中文混合字体换行原先逐字形扫描整组字形寻找下一个 cluster，再为每个候选行扫描整个段落的 cluster。现在先建立有序的 cluster 边界，二分查找候选范围，只累加完整落在该行的 cluster；换行机会和首个绘制字体也使用有序范围查找。字体家族名称解析按不可变字体 face 缓存，字节和 face index 的字体身份不变。

桌面选择变化原先还会重建兼容显示快照并重新预检、计算整篇指纹。现在首次完整核对后保留不可变输入索引，后续同一个索引的选区变化可复用结果。字体和排版 profile 继续核对，新布局和切换文档清空该记录；不同索引仍做完整校验。没有用版本号相同代替内容相同，连续 IME 预览也不能误命中。

未更改导入预算、图片完整性检查、保护与拒绝规则、兼容显示范围、正式输出限制、依赖或公共锁文件。引擎仍负责编辑，布局不修改来源模型。

## 前后对比

使用同一个新增的 `open_perf` 示例、同一台机器、相同 dev 构建配置及宋体 `simsun.ttc` face 0。基线源文件临时替换为 `2fdef5b` 的对应文件运行后恢复，再运行优化版本；每份文档每版本运行 5 次。两组均使用已加载字体和系统文件缓存，以下为各文档 5 次完整链路耗时的中位数。

完整链路包括读取、`DocxSession` 导入、`TextInput` 索引、兼容显示快照、整篇分页、第一张页面 CPU 栅格化。它不包括原生文件对话框、绑定文件的存储元数据检查、任务调度和 GPU 上传，也不等同于点击到可交互的 GUI 耗时。字体首次加载单独记录，不计入每份文档的打开时间；额外的完整布局核对单独输出为 `reuse_ms`。本次没有把选择复用缓存的收益计入打开加速数值。

复现方式（PowerShell 7，路径替换为本机样例）：

```powershell
$env:JOYWORD_PERF_RUNS = '5'
cargo run -p joyword --example open_perf --locked -- 'C:\Windows\Fonts\simsun.ttc' 0 'D:\samples\sample.docx'
```

CSV 只输出样例序号、阶段耗时、页数、遗漏计数和场景摘要，不输出文档正文。正式性能验收要求的冷启动次数、事件数量及 p95/p99 未在本次完成；上述结果仅为本机五份样例的 dev 构建性能对比，不代表 Release 或全部文档的延迟保证。

## 自动验证与 GUI 复验

新增回归覆盖 80 行表格中行和单元格的前缀遮蔽、原 XML 字节保留、候选行部分 cluster 边界、已校验选区复用后的不同来源／不同 profile 拒绝，以及同版本连续 IME 预览内容变化。原有表格编辑、导出、撤销、布局预算和过期任务测试继续执行。

最初原生 GUI 窗口激活连续返回 `failed to activate captured window`；用户将 JoyWord 置于前台后，恢复原生自动操作和截图观察，完成本轮五份文档的复验。操作只针对新建测试副本，未保存到来源文档。

GUI 发现两个表格光标问题并修复：同一视觉行的不同单元格原先只按纵坐标命中，点击右侧单元格可能落到左侧；现在纵向距离相同时用横向光标距离区分。Home/End 查找当前行原先只比较页码与纵坐标，现在同时比较段落身份，避免跳入相邻单元格。新增双单元格逐停靠点命中回归，修复前失败、修复后通过；最终 GUI 在五份文档验证 End，在章节整合版同时验证 Home 和 End。两项修复不改变页面场景；修复命中逻辑后五份原文档各一次完整链路摘要仍与基线一致。

五份副本均完成封面加载、查找定位表格、点击右侧单元格、追加独立标记、观察换行与行高、撤销、重做、保存、正常关闭应用及重启后从文件对话框重新打开磁盘副本。标题恢复为实际文件名且无未保存标记，可访问正文包含保存的标记；未把启动时的恢复会话计作磁盘重开。修订版另目视确认跨页表格续页的重复表头。这些是原生 GUI 自动操作和截图核对，不替代用户人工验收或完整 Word 版式保真验收。

独立 ZIP/XML 检查确认五份副本各有且仅有一个标记，均位于第一张表第二行第三个单元格；每份仅一个段落变化，其他文字、表格／网格／行／单元格属性和段落数量不变。包成员清单一致，除 `word/document.xml` 外全部成员的解压字节相同，五份来源 SHA-256 未变。GUI 状态、截图和包检查结果只保存在被忽略的本机验证目录，不提交私有内容。
