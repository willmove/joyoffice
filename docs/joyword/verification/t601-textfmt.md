# T601 HTML、Markdown 与文本双向转换自动化证据（2026-10-28）

## 交付范围
1. **纯文本 (TXT) 导入与导出**：
   - 编码检测：支持 UTF-8、带 BOM 的 UTF-8、UTF-16LE、UTF-16BE 及容错回退。
   - 换行规范化：统一将 `\r\n` 与 `\r` 规范化为 `\n`。
   - 导出选项：支持配置输出 LF 或 CRLF 换行；表格与复杂对象扁平化并提供转换损失报告。
2. **Markdown (CommonMark + GFM) 双向转换**：
   - 导入：标题 `#`、代码块 ```` `、加粗 `**`、斜体 `*`、删除线 `~~`、行内代码 `` ` ``、引用 `>`、GFM 规范表格 `| ... |`。
   - 安全策略：检测并阻断 `javascript:`、`file:` 与 UNC 路径等恶意外链，记录在损失报告中。
   - 导出：段落样式映射为 Markdown 语法标记，复杂元素降级并汇报损失。
3. **受控 HTML5 双向转换**：
   - 导入：安全白名单标签（`<p>`, `<h1>`-`<h6>`, `<strong>`, `<b>`, `<em>`, `<i>`, `<del>`, `<s>`, `<table>`, `<tr>`, `<td>`, `<a>`），实体编解码。
   - 安全净化：剥离 `<script>`, `<style>`, `<iframe>`, `<object>`, `<embed>` 等危险标签，阻断恶意伪协议。
   - 导出：生成自包含 HTML5 文档，严格字符转义防止 XSS 注入。

## 自动测试命令与结果
```bash
cargo test -p joyword-textfmt
```
3 项综合测试全部通过。
