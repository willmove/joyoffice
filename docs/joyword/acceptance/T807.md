## GUI 抽查脚本

独立测试 profile 打开模板副本，从文件菜单选择邮件合并。先完成三字段映射，循环查看三条记录，再取消；核对父目录为空且模板／CSV SHA-256 不变。再次运行，循环更换列并确认，选择生成全部及已有空父目录；核对三封文件与预览、原始来源一致，原模板未改变。以真实 Word 与 WPS 打开含多行值的第三封，核对一页、标题居中粗体、收件人粗体、单位换行和编号 003，无修复提示；关闭测试文档，不执行云端操作。记录二进制散列、原生窗口观察和磁盘读回，不能用 CLI 结果替代桌面生成。
