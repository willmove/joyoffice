## GUI 抽查脚本

1. 按报告命令构建 validation 应用；仅在隔离测试进程设置 JOYWORD_VALIDATION_IO_GATE=1。通道暂停真实作业入口，导入、导出校验、文件 IO 和回调仍用生产路径。
2. 打开 2000 段 A，暂停时输入 BUF_A、Ctrl+B、Esc；另存旧文档，独立读回含 BUF_A 且无加粗，源件 hash 不变。
3. 保持取消 A 的作业等待，再打开 B 并输入 BUF_B；放行最早 A，再输入 LATE_B，放行 B；B 接受两个缓冲串。
4. 在 B 开头输入 SAVE_N，开始另存但暂停 IO，再输入 PLUS 并 Ctrl+W；截图应提示保存开始后的修改不在该次保存中。Esc 取消关闭后放行；文件 N 无 PLUS，后续另存包含 PLUS。
5. 再开始保存 B，打开 C、输入 NEW_C，再放行 B 保存；B 文件仍为 B，C 标题、内容和未保存提示不受影响。
6. 全程只操作测试自有进程与临时文档。普通构建复跑 T104 恢复用例，确保没有暂停条或测试开关依赖。

X11 事件为系统合成键鼠，截图为实际窗口像素。通道控制等待时长，不测磁盘速度；Windows／macOS 的本轮慢作业窗口、真实系统 IME、设备断电和性能矩阵仍未验证。既有原件保存／跨文档自动证据与历史 Windows 保存验收继续保留，T110 的元数据观测工作不因本任务 done 而关闭。
