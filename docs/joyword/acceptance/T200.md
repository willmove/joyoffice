## GUI 抽查脚本

本切片未执行下列图形界面步骤，不作为通过记录。

1. 打开 [DOCX-MIN-002.docx](../../../tests/fixtures/docx/DOCX-MIN-002.docx)。标题应为粗体、大于正文。样式面板里点正文或标题，一次撤销应恢复。
2. 编辑菜单「查找下一个」（Ctrl 或 Cmd+F）。勾选「全半角」后，半角查询应命中全角形式。取消勾选后不应命中。
3. 勾选「正则」。查找 `(\d+)`，替换为 `第$1组`。数字应被展开；`$$` 应变成一个 `$`。不勾选正则时 `$1` 保持字面量。非法模式 `(` 应拒绝且正文不变。一次撤销恢复全部替换。
4. 选中带直接格式的一段，编辑菜单「格式刷」，刷到另一段，状态栏出现已应用格式。一次撤销恢复目标段。
5. 做两级编号或项目符号，在上级之后插入一项，下级计数应重启。撤销后标签回到原样。
6. 接上一步，另存为新文件，用 Word 或 WPS 打开：新点的项目符号应正常显示，`word/numbering.xml` 里应多出追加的定义，文件原有编号定义的字节不应被重写。这一步是编号写回唯一的人工对照，本清单没有执行。
7. 打开只读的 [DOCX-MIN-005.docx](../../../tests/fixtures/docx/DOCX-MIN-005.docx)。查找可用，替换应被拒绝。
