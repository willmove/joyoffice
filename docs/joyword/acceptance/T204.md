# T204 PDF 与打印

任务原文：

> 自动验证：页面几何一致、PDF 文本／链接、纸型和打印范围测试。

> 人工验收：两个独立阅读器检查 PDF；真实打印或平台打印到文件。

> 产物：PageScene 完整页面输出、可选文本 PDF、平台打印层（GPUI 无打印接口）与预览，以及 PageScene 的 CPU 光栅后端。

> 错误路径：布局未稳定、字体不可嵌入、打印取消或设备失败不报告成功。

状态保持 `in_progress`。本清单不把人工验收标成完成。

## GUI 抽查脚本

1. 打开 `tests/fixtures/docx/DOCX-SAMPLE-001.docx`。
2. 文件菜单选「导出 PDF」，保存到临时目录。
3. 用两个彼此独立的 PDF 阅读器打开同一文件，看文字、链接和页数是否一致。
4. 文件菜单选「打印」，范围填 1，份数填 1，打印到文件。
5. 看生成的 PDF 只有指定页；取消对话框时目录里不应出现新文件。
6. 本机没有打印机时，只记录「打印到文件」，不要勾人工验收里的真实打印。
