# T300 修订

任务原文：

> 自动验证：原始／最终投影、接受／拒绝、undo 与文件往返性质测试。

> 人工验收：在 Word 与 JoyWord 交换文字修订，逐项和批量接受／拒绝。

> 产物：插入／删除／移动、作者时间、分组、四种视图（排版随投影变化）和局部处理。

> 错误路径：交叉范围、已有修订内编辑和不完整移动对有明确语义。

## GUI 抽查脚本

1. 打开一份只含文字插入和删除的文档（可从 `tests/fixtures/docx/DOCX-MIN-001.docx` 另存后自行键入；本仓库没有单独的修订样例文件）。
2. 审阅功能区打开「跟踪修订」，输入姓名作为作者，键入一段再删除一段。
3. 切换「所有标记」「最终」和「原始」，看页边色条是否只在所有标记时出现。
4. 逐项接受一处、拒绝一处，再撤销，确认文字回到上一步。
5. 选「全部接受」，保存，用 Word 或 WPS 打开，逐项看插入删除是否与 JoyWord 一致。
6. 本清单在第 5 步没有本机记录之前，不关闭人工验收。
