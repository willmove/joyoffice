# T203 验收清单

状态仍是 `in_progress`。2026-10-20 核对：页面相对 wrapSquare 已有自动测试。进度总览里「绕排未做」已经过时。wrapTight、wrapThrough、wrapTopAndBottom、衬于文字下方和非页面相对位置仍未做。Word／WPS／浏览器双向粘贴没有在本环境执行。

>

>

>
> 错误路径：畸形富文本、远程资源、过大图片和 ID 冲突不执行活动内容。

## GUI 抽查脚本

本环境没有 Word、WPS、浏览器或图形会话。下列步骤不作为通过记录。

1. 打开 [DOCX-MIN-004.docx](../../../tests/fixtures/docx/DOCX-MIN-004.docx)。外部超链接应有下划线。Ctrl 或 Cmd 加点击只应对 http、https、mailto 交给系统打开；javascript 与 file 不应打开。
2. 插入一张本地 PNG。图片后的文字在宽度够时应留在同一行。复制选中的图片，粘贴应再插入一张，且相同字节共用资源。一次撤销去掉这一张。
3. 从浏览器复制一段带粗体和脚本的 HTML，粘贴进文档。粗体应留下，脚本和图片不应执行或取回。
4. 从 Word 或 WPS 复制列表、表格和图片，比较 JoyWord 粘贴结果与原文。本产品没有粘贴选项对话框，富文本只走文本嗅探。
5. 若样例含页面相对的方形绕排，正文应避开矩形。紧密、穿越、上下型绕排应保持原样且该段锁定。
