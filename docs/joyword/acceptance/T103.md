## GUI 抽查脚本

本环境没有 Word、WPS 或图形会话。下列步骤不作为通过记录。

1. 打开 [DOCX-MIN-001.docx](../../../tests/fixtures/docx/DOCX-MIN-001.docx)，改一个字，另存为新文件，退出后重新打开，正文应含改动。
2. 打开 [DOCX-MIN-003.docx](../../../tests/fixtures/docx/DOCX-MIN-003.docx)。不支持的块应仍在包里；能编辑的段落保存后，未知部件字节不变。
3. 打开 [DOCX-MIN-005.docx](../../../tests/fixtures/docx/DOCX-MIN-005.docx)。文档应只读，保存不得改原件。
4. 用固定 Word 与 WPS 打开 JoyWord 另存的副本，再存回，由 JoyWord 重新打开。正文、未知部件和只读原因应与保存前的说明一致。
5. 在保存对话框里取消或制造失败（例如目标已存在且选择不覆盖）。原件字节应保持。
