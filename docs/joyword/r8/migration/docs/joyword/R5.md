## 文件与事务

- 桌面文件选择后先在后台有界读取，返回时核对文档身份、版本、选区及请求代次；Excel 多工作表明确询问名称。
- 表单绑定文档、内核版本、呈现版本和选区；输入法尚在组合时不提交。
- 仅切换标记或预览也更新呈现版本，避免原位使用旧位图。审阅投影传到分页和光栅快照。
- 合并/导出持有不可变快照，在后台生成并用新文件发布方式输出，拒绝覆盖已有路径；不会替换当前模板、清除当前 dirty 或继承原件来源戳。
- 合并全部记录最多 1000 条；生成前用计数序列化器估算并限制 32 MiB 展开；收件人输入 16 MiB，比较 DOCX 64 MiB，输出 256 MiB。
- 桌面宏最多 256 步/1 MiB，禁止文件、网络服务及会话命令。失败回放恢复文档和编辑历史；版本保持单调，避免旧表单重新有效。
- 非 DOCX 原件按保存时转为 DOCX 副本；现有 DOCX 安全保存、外部改动检查与 Windows 元数据确认行为继续沿用。
