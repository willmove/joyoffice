## 渲染与编辑

- 页面位置使用双精度前缀索引。滚动通过二分定位视口，按可见页、距视口两页内的邻页依次光栅化。缩放以当前页及页内位置为锚点。
- 同一文档版本的光栅任务共享不可变场景。任务检查文档版本、缩放、设备像素比及目标页，取消的任务在绘制指令之间检查取消标记，已经提交给 Vello 的调用运行至返回。
- 页面图像使用跨缩放级别的 LRU，总预算 16,777,216 像素。单页上限 4,194,304 像素，后台同时处理一页。光标、选区和拖动继续由 GPUI 叠加。像素预算适用于缓存和在途页面，进程工作集还包含内核布局、编辑历史和图形运行时。
- 编辑只在 CLI 检查等显式请求时展开全文文本，IME 更新恢复编辑快照后跳过一次中间分页。首次排版前设置真实文件路径，避免首次编辑使段落缓存整体失效。
- 长文档中完全位于一页的段落，行数、垂直度量和换行类型稳定时局部重整，并只使修改页的图像失效。跨页段落、复杂文档与影响页流的修改仍完整分页。保留 Vello CPU 页面光栅和 GPUI 图像合成，直接字形、路径绘制仍待验证字体身份和图形保真。

## 界面与无障碍

- 对照本机 JoySheet 的销售样例，复用 `joyoffice-ui` 的标题栏、紧凑快捷工具、绿色主题、功能区度量及状态栏。命令搜索支持中英文、`Ctrl/Cmd+K` 和 13 个桌面命令。JoyWord 保留文档功能区分组和分页画布，其他窗格、对话框及跨主题的一致性仍待逐项验证。
- 沿用宿主 AccessKit 的文本运行节点及 UTF-16 位置换算。文档区域向系统暴露当前段落和选区，选择回调校验文档、版本和字素边界。提供功能区选项卡角色和键盘激活。Windows UI Automation 已读取正文段落，整篇文档导航和读屏应用验证待补。
- 原生单文件拖放进入同一个打开流程。拖放、多屏和 DPI 切换仍需原生验收。
