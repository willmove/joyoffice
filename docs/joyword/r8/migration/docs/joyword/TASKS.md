# JoyWord 重构任务清单

日期：2026-11-04。共 112 项，当前状态为 planned 32、in_progress 43、implemented 12、verified 25。机器清单 [tasks.json](tasks.json) 是任务字段的维护入口。阶段总览与实施规则见 [PLAN.md](PLAN.md)，验收证据规则见 [ACCEPTANCE.md](ACCEPTANCE.md)。

状态顺序为 planned → in_progress → implemented → verified → accepted。implemented 只表示代码落地；verified 表示指定自动检查通过；accepted 需要本阶段桌面演示与规定的人工验收。平台缺少环境单列未验证，不能写成通过。

R6 从 R2 后开始，R7 从 R1 后开始；二者可与功能迁移交错实施。各任务依赖是最低前置条件，每次提交还须保持已经交付的阶段可构建、可运行。
