# 套件共享边界独立规格入口

2026-10-30 · T901 / SUITE-001 · 规格入口完成，JoySheet / JoyDeck 未开始实现。

输入为 [JoyWord 架构](ARCHITECTURE.md)、[需求](SPEC.md) 及现有 crate 分层。
本文件规定新应用的独立模型和可共享设施，作为下一轮设计评审入口；不以重构稳定模块
或创建空壳应用作为交付，也不表示 T704 或整个 M9 发布阶段已通过。

## 模型与编辑责任

JoyWord 继续以 story、段落、run、表格、批注、修订为内容模型，由 engine 编辑、
layout 只读消费快照。JoySheet 单独建模工作簿、工作表、单元格地址、公式依赖图、
值类型与计算错误。JoyDeck 单独建模演示文稿、幻灯片、母版、形状层次、连接和时间线。
Word 的表格不是工作表，Word 的 PageScene 不是幻灯片模型；两者不得通过复用 Word AST 强行表达。
撤销、标识、位置映射和快照概念可以借鉴，各应用事务必须验证自己的不变量。

| 设施 | 可共享部分 | 独立责任／禁止混入 |
| --- | --- | --- |
| OPC / ZIP / XML | 包关系、预算、路径校验、未知字节保留 | Word、表格、幻灯片语义由各格式层解释 |
| 字体与资源 | 实际字体字节及 face 身份、图像摘要和许可检查 | 每应用选择回退、布局与缺字策略 |
| 主题 | 明确版本的颜色、字体、效果 token 及来源 | Word 样式、Sheet 数字格式、Deck 母版独立解析 |
| 平台与 shell | 窗口、对话框、剪贴板传输、快捷键本地化设施 | 命令可用性、参数及事务由各应用定义 |
| 存储恢复 | 原子发布、无覆盖、冲突探测、日志封装 | 日志操作格式、迁移和恢复由应用及版本标识 |
| 渲染与 PDF | 字体嵌入、图像校验、低层绘制及输出预算 | 工作表分页／打印区域、幻灯片版面分别产生场景 |
| AI 与隐私 | 显式授权、Provider 关闭、预算、审计 | 不同应用的选区含义与可写操作独立授权 |

共享的第一候选是目前不含 Word 语义的 joyoffice-opc；不得把 Word 导入逻辑下沉其中。
joyword-model、engine、layout 和 docx 继续属于 JoyWord。
其他模块只在第二个真实消费者出现且契约测试齐备后考虑提取，不能仅改名就声称通用。

## 资源与主题交换契约

交换使用带版本的显式 envelope：来源应用／格式、内容类型、原始资源摘要、
允许的表示形式及逐元素损失计划。目标先预检再由用户接受；预览取消不创建目标内容。
二进制资源只按实际字节标识，字体另含 face 标识，不按文件名或字体名冒充相同资源。
主题 token 携带命名空间与回退值，目标不能把未知 token 无声映射为默认黑色。
保留未知 XML 和关系必须同时保留其所有依赖；不能安全保留的对象要求独立副本或拒绝。

数值、公式、富文本、图片和矢量图是不同的表示形式。公式转 Word 表格时，
必须说明是只读计算值快照，不得声称继续计算；Deck 对象转图片必须明确丢失可编辑性。
跨应用粘贴不执行宏或外链，不自动抓取远程资源。资源有独立字节、数量和解码预算。

## 人工审查的跨应用工作流

| 场景 | 预期行为和验收观察 |
| --- | --- |
| Sheet 区域粘贴到 Word | 选择数值快照或图片；公式、数字格式、隐藏行损失明示；取消不改变文档 |
| Word 表格送到 Sheet | 文本和数值推断可预览；合并单元格、脚注、批注逐项说明；原 Word 表格不变 |
| Word 图片送到 Deck | 原始图像摘要及尺寸可核对；来源替代文本保留；无字体资源时不伪称文字可编辑 |
| Deck 主题导入 Word | 展示颜色／字体映射；母版和时间线留在 Deck；未知效果原样保留或拒绝 |
| 源更新后重开目标 | 默认是独立快照；链接需另行授权、标注来源，离线不覆盖本地内容 |
| 缺字体或受限字体 | 展示替换或拒绝输出，系统字体不得随产物擅自分发 |

这些场景已作规格层面的语义与错误路径审查；当前没有虚构尚不存在应用的 GUI 互操作结果。

## 下一轮验证与迁移门槛

独立应用先定义模型不变量、格式支持矩阵、事务／撤销、预算和源文件保护测试。
共享 API 候选须有至少两个真实调用者、独立契约测试和版本演进方案。
契约测试覆盖相同资源的身份一致性、未知主题 token、损失计划接受／取消、
恶意包路径、资源炸弹、外链零访问、源文件散列不变、升级失败保留旧日志。
GUI 验收分别覆盖工作表键盘导航与公式错误、幻灯片层次与演示、跨应用交换预检。

提取步骤是先记录现有行为并测试，再添加通用增量 API、迁移两个消费者，
最后在兼容窗口结束后移除旧入口；不一次性迁移稳定 Word 模块。
首个里程碑只评审各应用模型与共享候选，不承诺公式引擎、动画、云同步或套件安装器已实现。
正式应用需求、共享 schema、资源预算数值和发布计划留给独立立项确认。
