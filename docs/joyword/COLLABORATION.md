# 实时协作独立规格入口

2026-10-30 · T900 / COLLAB-001 · 规格入口完成，协议实现与服务发布未开始。

本规格以 [当前架构](ARCHITECTURE.md)、[AI 授权边界](AI.md) 和
[需求](SPEC.md) 为输入。它定义下一轮协作项目的范围、决策与验收入口；
不修改本地编辑、恢复、文件保存或默认无网络行为，不表示 T704 已通过。

## 产品与身份边界

第一目标是两位有编辑权限的用户共同审阅一份文档，支持断网后继续工作及显式恢复。
打开本地文件不会创建账户、上传文档或加入共享空间。进入协作必须明确选择文档、
服务目的地、共享范围及身份；AI Provider 的选区授权不能充当协作上传授权。
本地文件、共享文档和下载副本显示不同来源，不能因名称相同互相覆盖。

服务身份至少包含租户、用户、设备与会话。文档身份由服务分配，局部节点 ID 只在
其所属文档及世代中有效。复制或导入文档创建新的文档身份，不能拼接既有事务历史。
账户注册、身份提供者、设备撤销和找回机制须在服务规格中独立实现；客户端不保存明文凭据。

## 同步事务与冲突

现有 engine 事务、位置映射、撤销及 model 快照是本地契约，不是网络协议。
NodeId、版本号和稳定锚点不保证分布式唯一性、收敛或因果关系，不能直接作为 CRDT。
下一轮必须在 OT、CRDT 或服务端串行化中完成有依据的选择，并证明以下可观察结果。

每个提交携带协议版本、文档及世代、设备操作标识、基线修订和事务摘要。
服务器完成权限、预算与语义验证后给出可重试的确认；相同操作标识重复提交不能重复应用。
确认前界面标为待同步；收到其他设备操作后只通过 engine 事务更新模型，layout 保持只读。
服务端拒绝不能伪装成本地保存成功。未知协议版本、未知操作和未知 XML 不能静默丢弃。

| 冲突场景 | 必须定义的行为 |
| --- | --- |
| 同一锚点并发插入 | 固定且与到达顺序无关的排序；双方最终文字一致 |
| 删除范围与范围内插入并发 | 明确插入内容是否存活；显示可审查的冲突结果 |
| 删除段落与格式修改并发 | 不产生悬空引用；被拒绝的格式操作可追溯 |
| 表格合并与单元格编辑并发 | 保留双方内容或拒绝结构操作并提供独立副本 |
| 修订接受与批注回复并发 | 批注锚点迁移或转为已脱离锚点的线程，回复不丢失 |
| 撤销与远端编辑交错 | 只撤销用户自己的操作，不恢复已被撤销的远端内容 |
| 导入含未知对象的文档 | 保留原始部件；不支持的编辑区锁定且解释原因 |

正式协议必须为每行写出初态、各端操作、所有允许的传输顺序及精确终态；
未完成这些决定与收敛验证前不得连接生产同步。

## 权限、离线与恢复

角色初步划分所有者、编辑者、审阅者和只读者；逐操作权限在服务端验证。
审阅权限允许的批注、修订操作必须枚举，不能等同任意正文写权限。
撤销共享和设备失效后拒绝新提交及同步读取。已经下载的副本不能承诺远程抹除。
离线权限有期限；失效期间的操作保留为本地私有分支，重新授权后才能提出合并。

客户端将基线、未确认操作与确认游标分别持久化；网络确认和本地落盘之间崩溃时，
使用操作幂等性恢复，不能因为重发复制文字。同步日志和现有本地恢复日志分别标识格式，
升级失败保留原日志。服务重置或历史压缩导致基线过期时，提供本地副本及差异审查，
绝不自动用服务器版本覆盖未确认内容。离线恢复先验证身份与权限，再请求缺失历史。

光标及在线状态是短暂数据，不进文档或撤销历史；不携带选区正文，断线后过期。
订阅、队列、消息、附件、解压 XML 和重连重试必须有预算；超预算可诊断地断开，保留本地编辑。

## 服务运维与隐私

下一轮服务规格须给出传输加密、静态加密、密钥轮换、租户隔离、数据区域、
保留与删除期限、备份恢复目标和审计访问控制。审计记录身份与操作摘要，默认不写正文。
附件沿用内容字节校验，外链不自动读取，活动对象不执行。文档分享和遥测必须分开授权。
发布前进行故障注入、恢复演练与威胁建模；未定义 RPO/RTO 和值班职责不能声称服务可用性。

## 下一轮验证与人工场景

协议获确认后建立独立测试集合：乱序、丢包、重复、重连、时钟偏差、设备 ID 碰撞、
版本不兼容、权限撤销、跨租户请求、预算耗尽和服务恢复；保存种子及每端完整终态摘要。
收敛检查同时比较文字、格式、批注、修订、对象保留与位置映射，不能只比较可见文字。

人工验收必须逐步执行：

1. 两用户以不同角色加入同一共享文档，共同编辑、批注及接受修订，重开后核对终态。
2. B 断网继续修改，A 删除同一区域；B 重连审查冲突，双端保存独立副本并核对无丢失。
3. B 离线期间撤销其权限，B 重连只能导出私有副本，不能上传或继续读取共享历史。
4. 在发送后确认前强制结束客户端，重启后重发操作，只出现一次修改。
5. 服务恢复旧备份导致基线失效，保留本地未同步修改并明确要求重新建立基线。

以上是可执行验收定义，当前没有宣称运行了多用户服务。协议选择、账户服务、部署目标、
资源预算数值及正式性能指标是下一轮立项决策；本轮完成的是独立规格入口与场景审查。
