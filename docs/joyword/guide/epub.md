# EPUB 导出

在桌面「文件」页选择「导出 EPUB…」，审阅转换差异和数量后，选择一个新的 `.epub` 路径。导出包含会话中已提交的编辑。取消不会写入文件，等待期间如果文档、版本或呈现状态发生变化，需要重新发起导出。发布过程同步并读回临时文件，拒绝覆盖现有目标。

CLI 可以先生成只读计划，再明确接受转换损失并输出。

```text
joyword-cli epub book.docx --plan --title "示例" --language zh-CN --modified 2026-10-30T10:00:00Z
joyword-cli epub book.docx --output book.epub --accept-losses --title "示例" --language zh-CN --modified 2026-10-30T10:00:00Z
```

计划返回 schema 1 JSON，包含损失位置、说明、字节数、段落数和图片数。省略标题、语言或日期时，使用源文件名、`und` 或当前 UTC 时间。需要字节可复现时，显式固定元数据。同一输入与元数据的两次导出已通过字节比较。

支持 EPUB 3.3 重排正文、Unicode 和软换行、标题导航、基本字符样式、安全的外部链接、简单表格与内嵌 PNG／JPEG。EPUB 3 导航与 NCX 使用相同标题顺序，七至九级标题映射为 h6。转换差异包括纸张与分页、复杂样式和字体字节、包元数据。图片保留现有替代文字，缺失时使用通用文字并报告差异。

带保护、未决修订、隐藏文字、编号、批注、非空附加故事、域、内部链接、浮动或裁切图片、纵向合并表格等结构的文档可能被拒绝。CLI 在导入前检查 Word 包，桌面检查会话打开时捕获的源包。两者都会拒绝已识别的未知正文结构。CLI 输入 DOCX 上限 32 MiB，正文上限 4 MiB，导出上限 64 MiB。表格、文本 run、图片数量、图像字节和解码像素均有独立预算。

本轮验证覆盖独立 EPUBCheck 和包结构读回。阅读器显示、桌面实屏和无障碍验收见 [R8 验证记录](../r8/VALIDATION.md#windows-格式与编辑复验2026-11-05)。格式规范见 [W3C EPUB 3.3](https://www.w3.org/TR/epub-33/)。
