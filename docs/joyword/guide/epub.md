# EPUB 导出

从文件菜单选择“导出 EPUB”，先审阅逐元素转换差异，再选择一个新的 `.epub` 文件。首个确认按钮为取消；取消不会写入文件。导出使用当前文档快照，保留编辑状态、撤销历史和磁盘 DOCX。再次触发导出可请求取消，关闭文档窗口也会取消尚未发布的任务。

CLI 示例：

```text
joyword-cli epub book.docx --plan --title "示例" --language zh-CN --modified 2026-10-30T10:00:00Z
joyword-cli epub book.docx --output book.epub --accept-losses --title "示例" --language zh-CN --modified 2026-10-30T10:00:00Z
```

计划返回 schema 1 JSON，包含位置、差异、字节数、段落数和图片数，零写入。实际输出必须显式接受差异；同一输入和元数据生成相同字节。输出路径已存在则拒绝，临时文件读回后通过同目录硬链接发布；不支持硬链接的卷会报错。发布之后的临时文件清理失败会明确报告已发布文件路径，不删除完整结果。

支持 EPUB 3.3 重排正文、Unicode／软换行、标题目录、基础粗体／斜体／字号／RGB／下划线、允许方案的外部超链接、简单表格和已验证 PNG／JPEG。目录为平面列表，七至九级标题映射 h6；图片使用响应式宽度和通用替代文字，需要用户补审。字体字节、Word 分页、包元数据及未使用扩展不随 EPUB 输出；差异报告会明确列出。

未决修订、隐藏文字、编号、内容控件、未知保留结构、批注／域／书签、非空页眉脚注等额外故事、内部链接、浮动图片和纵向合并表格明确拒绝。输入 DOCX 上限 32 MiB；导出正文 4 MiB、块 20000、run 32768、图片 1024、图片资源合计 32 MiB、输出 64 MiB。单图最多 8 MiB、4096 边长和 16777216 像素；声明类型必须符合实际字节。

语言元数据使用 CLI 指定值，桌面默认 `und`；尚未逐 run 迁移来源语言标签。复杂 DOCX 若被桌面编辑会话以 UnsupportedBody 拒绝，可用 CLI 做支持范围内的只读计划；这不表示桌面已经支持这些编辑结构。本切片不表示 PDF/A 已实现，也不声明 EPUB 无障碍合规。自动校验、GUI 与未覆盖项见 [验证记录](../verification/m8-focus-epub-20261030.md) 和 [T806](../acceptance/T806.md)。

新增可选 NCX 兼容旧阅读器，与 EPUB 3 nav 保持相同标题顺序；独立 SumatraPDF 已显示两章目录并支持中文检索，混合文字缺字仍未通过。PDF/A CLI 能力见 [归档指南](pdfa.md)，本轮验收见 [报告](../verification/m8-archive-20261030.md)。
