# JoyDeck M6 文稿设计开发预览

本机 macOS ARM64 release 开发包，未签名/公证。运行 `./joydeck` 或 Launch.command。

顶部“文稿设计”打开右侧可滚动面板。先“创建原创设计”，选择版式，再“应用选中版式”；可复制/重命名母版和版式、修改主题accent/背景/正文字体与母版标题字号，添加页码/固定日期占位符后重新应用。新名称、颜色、字号等输入在面板下方，点击相应按钮提交。删除在用版式或仍被引用的母版会拒绝。重置保留对象ID和内容并清除直接格式。仅文字占位符；不含完整母版画布编辑器。

同文稿新窗口：独立选择与当前页，共享一个写入者和undo/redo。修改会在其他窗口约100ms同步；远端修改取消本窗尚未提交的画布文字/手势草稿。保存按共享租约串行化，旧revision保存成功后新修改仍dirty；同文稿新窗可使用共享文件路径。新文稿窗口保持独立文稿。每个窗口的路径栏可另存；独立重开同文件仍使用外部指纹冲突保护。

面板还提供多行备注、作者/说明、固定字段日期、节创建/重命名/归页/保留页删除、大纲导航、区分大小写的文字查找/全部替换和字体替换。备注为显式提交；切页会载入目标页字段，未应用草稿不保存。其他窗口改过备注时拒绝旧草稿提交，可“刷新文稿字段”后重编。

复制所选页后在另一文稿粘贴：选择源格式或目标文稿首个主题。重新映射页/对象/母版/版式/主题/节ID并自持媒体；不同尺寸按横纵比例缩放，字号按较小比例缩放。目标主题缺少源模板要求的槽位时整次拒绝。动态页码/日期按目标文稿上下文解析。剪贴板JSON限8 MiB。普通对象复制会固化继承外观，避免在目标文稿留下悬空占位符引用。

原有PNG/JPEG导入、EXIF、裁剪、剪贴板、对齐分布与CPU/GPUI切换保留。schema1.4/minReader5/必需design-v1，读旧1.0–1.3；旧版本拒绝新文件，请保留原文稿。PPTX仍只读，未实现母版主题的PPTX往返。

完整M6仍未完成：图片/非文字占位符、完整母版编辑、渐变/图片/图案背景/模板专用格式、完整格式面板、autofit/列/锚点/链接、节折叠/整体移动、完整排序/备注视图、多文档标签与可访问性/双语资源、跨平台/读屏与完整AT-09/05/14；M0–M5原有缺口保留。此包是已验证增量，不宣称整阶段完成。

验证：`python3 scripts/smoke-native.py M0 M1 M2 M3 M4 --binary ./joydeck`；macOS带Pillow/numpy的Python运行 `scripts/verify-m5.py --binary ./joydeck` 和 `scripts/verify-m6.py --binary ./joydeck` 做窗口像素/图片剪贴板/同文档双窗口与跨文档页复制；系统拼音使用 `scripts/smoke-macos-ime.py --binary ./joydeck`。正常结束恢复原剪贴板/输入源，异常中断不保证恢复。这些是原生/OS adapter验证，不能代替物理输入及跨屏/三平台验收。
