# JoyDeck M0 Windows preview

Double-click joydeck.exe to launch the native GPUI diagnostics window.

This is an unsigned development build for Windows x64, not an installer or a presentation editor. It demonstrates input, themes/languages, menus/dialogs, paths/images, multiple windows and cancellable background tasks. Close the window to quit; Ctrl+Q also quits. No Office installation or external application assets are required. System fonts and Windows graphics/runtime support are required.

Version: 0.1.0. GPUI Kit: 0.8.1. GPUI pre: 0.3.10. Rust: 1.98.1.

Physical IME/candidate positioning, multiple display DPI changes and macOS/Linux remain pending validation. Automated input adapter checks do not replace physical input method testing.

See SHA256.txt for this build's checksum and THIRD_PARTY.md/licenses for dependency provenance. Keep the package intact when moving it. This preview does not auto-update or upload telemetry.
