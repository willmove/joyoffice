# JoyDeck M2 · Windows x64

双击joydeck.exe启动编辑器。页面缩略图支持Ctrl多选、Shift范围选择、拖动重排或上移/下移；可新增、复制、删除、隐藏页。右侧可修改页面尺寸。

插入矩形/圆角矩形/椭圆/箭头/线/文本框。点击选择、Ctrl/Shift多选、空白处拖出框选。拖动对象移动；蓝色八点手柄缩放，黄色圆点旋转；Shift约束移动/等比缩放/15度旋转，Alt中心缩放。旋转对象采用等比缩放以避免剪切。一次手势一条撤销；Esc、移出窗口释放或窗口失活取消手势。对象列表支持多选、置顶/置底，右侧编辑位置、尺寸、文字、旋转、实色、描边、不透明度。混合值为空，保持不变。Ctrl+Z/Y撤销/重做。

填写.joydeck路径后保存（Ctrl+S）；当前文件按指纹检查后原子替换，其他已有目标须明确确认。检测到外部修改则拒绝保存，可改新路径另存。关闭窗口有保存后关闭、放弃、取消三条路径。初次创建依赖同卷硬链接；不支持的文件系统会明确报错。

恢复列表列出本机快照；恢复为未保存副本，不自动覆盖源文稿。正常提交后1秒空闲写快照，连续操作最多60秒触发；每会话保留3份，逻辑字节预算1 GiB。活跃实例有文件锁，损坏快照和索引隔离；旧版无锁快照只读导入，保留原文件。隔离/旧版文件计入预算，预算满时会提示停止写恢复，需处理本机恢复目录。恢复目录为LOCALAPPDATA/JoyDeck/recovery，含文稿正文。

原生格式为schemaMajor 1 / schemaMinor 1 / minReader 2，保留major1/minor0的读取升级。旧版应用会拒绝新文件；请使用本包。PPTX通过只读查看器打开，不支持写回。Windows本机已验证，macOS/Linux、多屏DPI、真实电源中断仍未验收；这是未签名debug包。依赖和校验值见THIRD_PARTY.md、licenses、SHA256.txt。
