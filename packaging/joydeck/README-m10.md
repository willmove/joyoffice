# JoyDeck M9/M10 本机开发预览

macOS ARM64；双击 JoyDeck.app 或 Launch.command。也可运行 `./joydeck --authoring-demo` 查看原创图表、图示和动画样例。此包未正式签名/公证，支持范围和验收状态见源码 STATUS.md、docs/31-m9-implementation-report.md、docs/32-m10-implementation-report.md。

工作区按本机 PowerPoint 对照调整：快速访问、开始/插入/设计/切换/动画/放映/视图、上下文页签、左侧缩略图、白色画布和备注区。开始保留剪贴板→幻灯片→字体→段落→绘图的顺序。格式栏按需打开；字体下拉使用实际系统字体，形状库、插入表格行列数对话框可用。Cmd/Ctrl+O/S/Shift+S，Cmd+N、Cmd+Shift+N，F5/Shift+F5；有些键可能被系统功能键设置占用。

插入→图表，支持柱形、条形、折线、面积、饼、环形和散点。选中图表后，“图表设计”提供类型切换、TSV、数据网格、标题/轴/单位/范围/调色板和图例/网格/标签。网格和TSV分别应用，未应用的内容是草稿；应用是单次撤销事务。散点采用成对X/Y列，空值不填零。每图1–256类别、1–16系列、最多4096点；全文稿16384点，数值绝对值≤1e12，粘贴≤128KiB。饼/环形图为单系列非负数据，环形图当前内径固定50%；面积图为非堆积类型，空值分段。

基础 SmartArt 图示提供列表/流程/层级、文本面板和布局切换，每行一个节点，Tab缩进，编辑器最多8层、64节点。导入受支持的SmartArt文本拓扑时会明确提示简化，原始布局/绘图缓存保留在源包。转换为形状会提示层级/布局/对象动画目标的损失，可撤销。不是完整的Office SmartArt引擎。

公开PPTX输出真实DrawingML图表和嵌入XLSX，缓存/工作簿由同一模型生成；基本图示输出普通形状组合。公开导入会核对支持的单列数值引用与工作簿；缓存冲突、组合/堆积/3D/chartex等不受支持对象给出诊断并保留原包。源码含本机PowerPoint16.114.1的原创交换样例：图表经Excel保存更新后改为133，JoyDeck独立重读；也包含旧缓存91/工作簿132的冲突样例。只有全部公开部件哈希匹配时才读取JoyDeck专有快照。

动画：选择对象，在“动画”添加出现、淡入、淡出、飞入、移动、缩放、旋转；右侧排序、开始规则、时间、重复/反向/倒回和按段落设置。当前UI重复快捷切换为1/2次，模型支持1–64次。预览与放映使用相同的确定性采样器，播放不改变原稿。切换支持无、淡化、推进、擦除和平滑子集；平滑需显式匹配名，同页不得重复，匹配的同类且内容一致对象插值几何/透明度，同资源图片插值裁剪；内容或资源变化/无匹配则交叉淡化。不支持任意路径、逐字或3D变形。

放映：Space/方向键推进；播放中点击先完成当前动画步，再继续下一步/页。左方向键返回上一动画步，跨页后退显示上一页末态；跳转重新开始。P暂停、B/W黑白屏、L激光、I墨迹、E清除、R重播、1–9跳转、Esc退出。墨迹最多256笔/2048点，可另存原生文稿副本或放弃，编辑中的原稿不变。对象内部页链接、自定义页序、循环和自动翻页在JoyDeck原生文稿中生效；公开PPTX尚未输出这些链接/自定义放映设置，导出前有损失说明。

演示者窗口提供当前/下一页、独立备注、计时、导航、当前动画步定位、查看观众窗口、屏幕选择/交换；观众窗口按Tab返回演示者窗口。只有一个有效屏幕时观众使用窗口模式；两个有效屏幕时可选择全屏目标。排练计时可保存到新文稿副本。观众时钟有唯一所有者，重建观众窗口不叠加计时；超过5秒的时钟间隔会暂停，不集中补播。当前仅验证单屏下双窗口及原有静态全屏流程；真实双屏/DPI/镜像/热插拔和系统睡眠唤醒仍待硬件验收。

原生schema1.8/minReader9，读取1.0–1.7；旧版拒绝新文稿，保留旧文件。源包保留写回仍限唯一单run/单段/单行文字修改；改变图表/图示/时间线请使用明确有损的新建PPTX。PNG/JPEG/PDF沿用M7：可见PDF为栅格，基础文字/表格有ActualText映射；图表/图示未提供精确文本选择、矢量PDF或Tagged PDF。没有媒体播放、录制或正式三平台Beta承诺。

测试需要解锁的macOS桌面，以及带Pillow/numpy/python-pptx/pypdf的Python；旧导出验证另需Poppler。`scripts/verify-m9-m10.py --binary ./joydeck`运行本机画布、图表工作簿和放映时钟验证。M0–M8与系统拼音的回归脚本一并提供。虚拟时钟/CPU基准/单屏双窗口不会被标为真实双屏或60fps达标。
